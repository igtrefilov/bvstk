# Формат карты регистров v1

JSON UTF-8, `schema_version: 1`.

## Общие требования

| Параметр | Требование |
|---|---|
| Размер | До 65536 байт |
| Неизвестные поля, неверные типы | Карта отклоняется целиком |
| JavaScript, функции, `eval` | Не поддерживаются |
| Комментарии, завершающие запятые | Недопустимы |
| Повторяющиеся ключи | Недопустимы; JSON-парсер браузера оставляет последнее значение без диагностики |

### Корень

| Поле | Значение |
|---|---|
| `schema_version` | Число `1`, независимо от версии профиля |
| `kind` | Строка `register_map` |
| `id` | ID карты, `[a-z][a-z0-9_]*`, до 64 символов |
| `device` | Непустое название модели |
| `bus` | `i2c` или `mdio`, должно совпасть с профилем |
| `width_bits` | `8` для I²C, `16` для MDIO |
| `register_count` | 1–256 для I²C, 1–32 для MDIO; ровно как в профиле |
| `source` | Объект с непустыми `title`, `document`, `revision`, `url`; URL начинается с `https://` |
| `notes` | Общее пояснение об интерпретации |
| `identity` | Необязательный список из 1–16 условий проверки модели |
| `registers` | По одному описанию каждого ресурса; при нескольких пространствах — всех локальных адресов каждого пространства |
| `summary` | 1–64 показателя сводки |

| Значение | Ограничение |
|---|---|
| Строковые подписи и пояснения | До 600 символов, если не указан иной предел |
| ID регистров, полей, показателей | Тот же шаблон, что у ID карты |
| Адреса и коды | Неотрицательные целые либо строки `0x...` в допустимой разрядности |

### Описание регистра

| Поле | Значение |
|---|---|
| `id` | Уникальный ID внутри карты |
| `address` | Адрес регистра |
| `space` | ID пространства из профиля; обязателен при `transport.address_spaces`, в остальных случаях запрещён |
| `name` | Краткое обозначение из документации |
| `label` | Подпись в интерфейсе |
| `section` | Раздел и страницы источника |
| `reserved` | Необязательный boolean, по умолчанию `false` |
| `note` | Необязательное пояснение |
| `fields` | 1–32 битовых поля, без пересечений и пропусков |

| Условие | Требование |
|---|---|
| Описание битов | Все биты, включая резервные, без пропусков |
| Резервный адрес | Перечислен; только поля `type=reserved`, `access=none` |
| Наличие адреса в карте | Не задаёт разрешение на чтение |

Пара `space`, `address` должна быть уникальной, как и ID регистра во всей
карте. `address` ограничен размером выбранного пространства.
Общее число регистров равно сумме `register_count` пространств профиля.
Расшифровщик вычисляет индекс кэша по порядку пространств, поэтому одинаковые
локальные адреса не смешиваются. Формат поля и ссылок сводки сохраняется.
Пример: [несколько адресных пространств](../address-spaces.md#карта-и-форма).

### Битовое поле

| Поле | Значение |
|---|---|
| `id`, `label` | Уникальный в регистре ID и подпись |
| `lsb`, `width` | Номер младшего бита от 0, длина от 1; без выхода за разрядность |
| `type` | `enum`, `uint`, `hex`, `reserved` |
| `access` | `ro`, `rw`, `wo`, `none`; физические свойства поля по документации устройства |
| `reset` | Текстовое описание значения после сброса; справочно |
| `values` | Только для `enum`, обязательно; объект код → `{label, tone?}` |
| `attributes` | Необязательный список атрибутов из таблицы ниже, не более 8 |
| `note` | Необязательное пояснение |
| `unit` | Необязательная единица измерения, до 40 символов |
| `scale`, `offset` | Только для `uint`, конечные числа; умолчания `1` и `0` |
| `ranges` | Только для `uint`, 1–32 диапазона пересчёта; вместо общих `scale` и `offset` |
| `write_value` | Необязательный фиксированный код для записи, только справочная информация |

Поля `wo` по кэшу чтения не расшифровываются.

### Пересчёт числовых значений

| Условие | Правило |
|---|---|
| `uint` | `код × scale + offset`, затем `unit` |
| `hex` | Шестнадцатеричная запись кода |
| Границы `ranges[].min`, `ranges[].max` | Включены; укладываются в разрядность поля |
| Порядок диапазонов | По возрастанию, без пересечений |
| `scale`, `offset` диапазона | Оба обязательны и конечны |
| Формула диапазона | Использует исходный код без вычитания `min`; результат конечен |
| Код вне диапазонов | «Не описано» |
| `ranges` и общие `scale`, `offset` | Взаимоисключающие |

### Коды и свойства полей

| Поле | Требование |
|---|---|
| `values` | До 256 записей; ключи — десятичные строки без ведущих нулей |
| `values.*.label` | Обязательно |
| Неописанный код | Не заменяется ближайшим допустимым |

| `tone` | Отображение |
|---|---|
| `ok` | Зелёный |
| `bad` | Красный |
| `warn` | Предупреждение |
| `offline` | Обычный текст; значение по умолчанию |
| `unknown` | Серый |

| Атрибут | Значение |
|---|---|
| `latch_low` | Сохраняется факт нуля до чтения |
| `latch_high` | Сохраняется факт единицы до чтения |
| `read_clear` | Физическое чтение очищает поле |
| `self_clear` | Самосброс |
| `nasr` | Программный сброс не меняет поле |
| `write_one_clear` | Запись единицы очищает |
| `write_any_clear` | Любая запись очищает |

Атрибуты справочные; физическое чтение просмотром карты не выполняется.

### Условия и показатели

Условие имеет ровно два поля:

| Поле | Значение |
|---|---|
| `field` | Ссылка на существующее нерезервное поле `<id регистра>.<id поля>` |
| `equals` | Сравниваемый числовой код в разрядности поля |

`equals` сравнивается с исходным кодом поля до `scale`, `offset` и подписей.

| Поле показателя `summary` | Требование |
|---|---|
| `id`, `label` | Обязательны |
| `field` или `cases` | Ровно одно из двух |
| `note` | Необязательное пояснение |
| `values` | Необязательная таблица подписей кодов |
| `cases` | 1–32 варианта |
| `cases[].when` | 1–16 условий, логическое И |
| Результат варианта | Фиксированные `label` и `tone` либо `field` с необязательной `values` |

| Условие выбора | Результат |
|---|---|
| Известное несовпадение | Вариант ложен |
| Несовпадений нет, данных для части условий нет | Неизвестный результат; выбор останавливается |
| Все варианты ложны | «Не определено» |
| Метка времени показателя | Самая старая запись, использованная для условий и выбранного поля |

### Проверка модели

| Состояние `identity` | Результат |
|---|---|
| Массив задан | Условия того же формата; для подтверждения модели должны совпасть все |
| Известное несовпадение | Сводка блокируется, выводится предупреждение; сырые значения и подробная расшифровка доступны |
| Идентификатор не прочитан | Проверка незавершена; доступные поля расшифровываются по выбранной карте |
| `identity` отсутствует | Модель не подтверждена; интерфейс сообщает, что проверка не задана |
