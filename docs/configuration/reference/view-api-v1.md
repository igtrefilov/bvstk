# API формы v1

[Объяснение](../register-map.md#Индивидуальная%20форма).
[Пример](../examples/device-display.md#Форма).

## Скрипт и вызовы

| Элемент | Контракт |
|---|---|
| Файл | JavaScript UTF-8, до 65536 байт |
| Внешние зависимости и `import` | Не поддерживаются |
| Экспорт | Объект `window.bvstkView` |
| `apiVersion` | Число `1` |
| `mount(root)` | Создание элементов формы, один вызов при запуске |
| `update(snapshot)` | Обновление по очередному снимку |
| Завершение | Уничтожение iframe при уходе со вкладки |

## Снимок

| Поле `snapshot` | Содержимое |
|---|---|
| `api_version` | Число `1` |
| `device` | `id`, `bus`, `presence`, `address_spaces`, `topology` |
| `stale` | Нет свежего ответа HTTP |
| `uptime_ms` | Оценка текущего времени с момента запуска PS, в мс; `null`, если прошивка не передала время |
| `sample_uptime_ms` | Время PS из последнего ответа HTTP без прибавления времени браузера; `null` при отсутствии |
| `routing` | Контекст свитча из HTTP: описание каналов, последнее чтение и непосредственно подключённые профили; `null` для обычного устройства или старой прошивки |
| `identity` | `true`, `false` или `null` |
| `map` | Проверенная карта |
| `cache` | Записи `reg`, `val`, `valid`, `source`, `updated_ms`; у блочных чтений I²C также `read_id`, `read_duration_ms` |
| `fields` | Результаты по ключам `<регистр>.<поле>` |
| `summary` | Массив показателей |

| Поле устройства | Значения |
|---|---|
| `presence` | `responding`, `unavailable`, `unknown` |
| `address_spaces[]` | `id`, числовой `address`, `first`, `register_count` |
| `first` | Начальный индекс пространства в кэше |
| Локальный регистр | `cache.reg = first + address` |
| Прямой профиль без пространств | Пустой `address_spaces` |
| `topology` | `controller`, `parent`, `channel`, `channels`; `null`, если описание недоступно |

`presence` обновляется вместе со снимком кэша. HTTP-ответ содержит
`uptime_ms`; между ответами браузер прибавляет прошедшее монотонное время.
Форма может сравнить его с `updated_ms` нужного ресурса и обозначить
устаревшие измерения. Порог устаревания выбирает форма устройства.
Уменьшение времени означает новый запуск PS и требует очистки локальной истории.
Для этой проверки предпочтительно `sample_uptime_ms`: оно не содержит
погрешности оценки времени браузером.

Форма может проверить совместное чтение нескольких байтов по `read_id`.
Все нужные записи должны быть достоверными, иметь одинаковые ненулевые
`read_id`, `updated_ms` и `read_duration_ms`. Значение длительности включает
маршрутизацию и задаёт верхнюю границу времени обмена. Отсутствие полей
означает, что совместное чтение не подтверждено.
Подробный [контракт кэша](../../interfaces/http/reference/devices.md#кэш-и-присутствие-устройства).

## Снимок свитча

`routing` передаётся вместе с кэшем. Его [формат](../../interfaces/http/reference/devices.md#контекст-свитча)
подходит всем I²C-профилям с описанием `protocol.switch`.

| Поле | Использование в форме |
|---|---|
| `control_reg`, `select_mask`, `channels` | Ресурс управления и правила выбора каналов из профиля |
| `last_read` | Последнее успешное физическое чтение: `reg`, `val`, `updated_ms`; `null` до первого чтения |
| `children` | Непосредственные дочерние профили с каналом, адресами и собственной `presence` |

Виджет PCA9545A использует `children` и `presence` для показа топологии и
готовности дочерних устройств. `last_read` остаётся частью контекста для
совместимости с API и общих потребителей, но не используется виджетом для
отображения текущего выбора канала или входов INT. Рабочий `cache.valid` при
этом может быть `false`; историческое чтение не меняет достоверность кэша.

Форма отмечает снимок устаревшим при потере HTTP-связи, отсутствии ответа
свитча или возрасте чтения более 15 секунд. Метка времени чтения остаётся
видимой. При перезапуске PS прежний снимок очищается.
На старой прошивке форма сохраняет только те действительные чтения кэша,
которые успела получить; сведения о дочерних профилях недоступны.

## Расшифрованные значения

| Результат поля | Содержимое |
|---|---|
| `status` | `known`, `unknown`, `missing`, `reserved` |
| `label`, `tone` | Готовое представление |
| `raw` | Исходный код в шестнадцатеричном виде либо `null` |
| `value` | Числовой код при наличии данных |
| `updated_ms` | Время наблюдения либо `null` |

| Показатель `summary[]` | Содержимое |
|---|---|
| `id` | ID показателя |
| `title` | Название |
| `label` | Результат |
| `status`, `tone`, `updated_ms` | Состояние и происхождение результата |
| `raw`, `note` | Необязательные дополнительные сведения |

## Среда выполнения

| Условие | Контракт |
|---|---|
| Область | Отдельный iframe, `sandbox="allow-scripts allow-downloads"` |
| Доступ к основной странице и операциям шины | Отсутствует |
| Сетевые запросы и внешние ресурсы | Блокируются CSP |
| Выгрузка снимка | Кнопка формы может сохранить локальный `Blob` через ссылку с атрибутом `download`; обмен с платой при этом не выполняется |
| Передача снимка | `postMessage`, вызов `update` внутри iframe |
| Ошибка скрипта | Возврат к стандартной сводке |
| Ошибка карты | Отсутствие расшифровки; остальные вкладки устройства доступны |
| Потеря связи | Последний снимок с `stale: true` |

Далее: [пример карты регистров и формы](../examples/device-display.md).
