# Матрица программного black-box теста PL SPI

Реализация: `src/apps/freertos/diagnostics/pl_spi_test/`. Сборка и запуск —
в [инструкции](../operations/pl-spi-test.md). Таблица описывает реализованные
проверки и ограничения, а не результаты аппаратного испытания.

## Основания и версия контракта

Использованы локальные материалы:

- `/home/ilya/Zynq/borya/SPI_page_context.md`: сохранённая страница SPI,
  обновление от 13 августа 2026, разделы 3, 5, 6, 7, 9 и 10;
- `/home/ilya/Zynq/borya/SPI_page_assets/page_68812882/`: новые таблица
  команд, схемы последовательностей и Tcl-примеры;
- текущий `artifacts/fpga/design.xsa`: адреса, IRQ и параметры инстанса;
- локальный Xilinx BSP: контракт AXI DMA и GIC.

Адреса берутся из XSA через BSP. Это выбранное пользователем разрешение
конфликта `0x43C50000`/`0x43C40000`, не автоматический поиск периферии.
Старые маски CSR и IRQ сохранены именно для проверки старого FIFO-контракта.
Для расширенного SD-пути явно выделен интеграционный профиль:
IRQ `[5:0] = {tx_full, rx_full, transaction, hard_init, soft_init, command}`;
SD-init: bit 0 — такты, bit 1 — команды, `[16:2]` — число тактов.
Численная раскладка расширенного IRQ установлена при изучении текущего
RTL, поскольку новые схемы называют события, но не дают полной таблицы
битов. Она служит адаптером доступа, а не доказательством соответствия RTL
старой документации. Тест не подбирает маски под наблюдаемый результат.

## Реализованные проверки

| ID | Требование / воздействие | Критерий и предел вывода |
|---|---|---|
| SW.ENCODING | Проверка самого инструмента | CRC7 CMD0/CMD8, CRC16/XMODEM и CRC32/IEEE на известных векторах; упаковка команд |
| ACCESS.CORE / BRAM | Доступ по адресу BSP | Чтение двух записанных шаблонов; не идентифицирует версию загруженной PL |
| REG.RESET_STATUS | CSR после reset | Нижние биты `0xA` по сохранённой карте; расхождение не маскируется |
| REG.RESET_CONFIG / RESET_WRITTEN | Сброс конфигурации | PACKET и DELAY равны нулю, включая сброс после ненулевой записи |
| REG.PACKET | Readback поля режима и 30-битного счётчика | `0x2D`, `0x2E`, `0x2F`, `0xFFFFFFFE`; старта нет |
| REG.DELAY | 32-битный регистр задержки | Значения 1, 2 и шаблоны с установленным старшим битом; измерение паузы сюда не входит |
| REG.RESET_BRAM | BRAM не очищается reset | Все слова 8 KiB сохраняют адресно-зависимый шаблон |
| DMA.RESET | Сброс обоих каналов | Сброшены Reset/Run, оба Halted, нет IOC/ошибок; весь DMACR не обязан быть нулём |
| FIFO.SINGLE / COUNTED / STREAM | Примеры 1 / 11 / 12 байт | Документированный end flag и длина принятого AXI-пакета; это не измерение фронтов на SPI |
| FIFO.READ_ENABLED | Положительная проверка RX | 4 байта и завершение через документированный FIFO-путь |
| FIFO.START_INHIBIT | `start=0` | Нет PS-видимого приёма/завершения, весь RX-буфер неизменен за интервал наблюдения; требует успешного положительного контроля |
| FIFO.WRITE_ONLY | `read_en=0` | Завершение без изменения всего RX-буфера; наблюдение продолжается до конца интервала, требуется положительный контроль |
| FIFO.TX_FULL / IRQ.TX_FULL | Заполнение TX при start=0 | Полнота в пределах FIFO_DEPTH из XSA и приход соответствующего IRQ; записей после full нет |
| SD.INIT / SD.REINIT | Аппаратная и командная инициализация | Свежие семь слов, CMD0=1, CMD8 R1=1/data=1AA, ACMD41=0, CMD55=0/1, CMD58 R1=0 и допустимые OCR power/voltage |
| IRQ.INIT / REINIT / COMMAND | Реальный IRQ в PS | Выполнился обработчик GIC соответствующей операции; отдельно от опроса IRQ |
| IRQ.ACK | Снятие IRQ | После ACK и повторного разрешения входа нет причины/повторного IRQ в интервале наблюдения |
| SD.CMD13 | Статус карты | Свежий двухбайтный R2 равен нулю |
| SD.CMD16 | Блок 512 байт | Завершение команды, свежий R1=0 |
| SD.CMD17 | Чтение сектора | Свежий R1=0, MM2S/S2MM IOC+Idle, точно 514 байт, CRC16 данных, сохранность границ |
| SD.GOLDEN | Независимый эталон содержимого | CRC32 сектора совпадает с заданным вне тестируемого пути; по умолчанию SKIP |
| SD.REPEAT | Повторные запросы | Все 514 байт совпадают в заданном числе запросов без сброса SPI; DMA переинициализируется |
| SD.ALTERNATE | Последовательность A/B/A | Второе A совпадает с первым; одинаковые сектора A/B не доказывают корректную адресацию |
| SD.RECOVER | Восстановление после reset | Повторная полная инициализация и прежний полный сектор |
| SD.CMD24 | Запись | Разные шаблоны во все scratch-сектора, затем побайтовое чтение всех; выявляет алиасинг адресов |
| SD.CMD32_33_38 | Стирание | Свежая готовность каждой команды, CMD13, чтение всех заранее заполненных секторов и ожидаемый erased byte |
| SD.MEDIA_BOUNDS | Границы изменения карты | Соседние сектора совпадают с предварительными снимками; дальние адреса этим не проверяются |
| CLEANUP | Остановка | DMA остановлен, ядро сброшено |

## Неоднозначности и непокрытые пункты

Старая страница относит end-of-transaction к IRQ bit 2, расширенный профиль
— к bit 3. Число SD-init тактов в старой статье начинается с bit 1,
в новом интерфейсе — с bit 2. Поэтому `0x193` в выбранном расширенном
профиле содержит поле 100, хотя часть схем подписывает его как 200 тактов.
Старый TX_FIFO доступ по `0x10` и новые DMA-команды проверяются отдельно.
Неудача FIFO-проверки не блокирует независимую проверку SD-пути.

Некоторые новые схемы и Tcl-примеры также расходятся по адресам,
дублированию команд, длинам и подписям регистров DMA. Здесь передаётся
один восьмибайтный дескриптор команды. CMD24 — 8+512+2=522 байта,
CMD17 — 512+2=514 байт приёма. Ожидается собственное завершение каждой
команды, а не только доставка дескриптора MM2S.

Упаковка зафиксирована явно: аргумент дескриптора хранится в обратном
порядке байтов (`512` -> слово `00020000`, как в Tcl CMD16); во втором
слове opcode/CRC7 занимают младшие два байта. Для payload CMD24 используется
описанный MSB-first порядок 32-битных слов; CRC16 находится в младшей
половине последнего слова, как на рисунке CMD24. RX распаковывается от
младшего байта слова, CRC16 сектора проверяется программно. При несовпадении
тест не пробует перестановки, пока одна из них случайно не даст PASS.
Из-за неполноты описания DMA payload/tail ошибка write/readback требует
проверки этой интерпретации наряду с самой PL.

Для FIFO-примеров точный PS-критерий требует завершённый AXI-пакет нужной
длины. Старая страница недостаточно описывает TLAST и выгрузку неполного
32-битного RX-слова для 1/11 байт. Тайм-аут/другая длина фиксируются как
неудача этого программного сценария; они сами по себе не доказывают,
что на SPI было передано неправильное число байт. Снимок IRQ позволяет
отделить отсутствие завершения от отсутствия выгрузки RX.

Следующие ID всегда остаются SKIP/BLOCKED в этом стенде:

| ID | Причина |
|---|---|
| PHY.TIMING | Нет наблюдения частоты, фаз, CS, межпакетных пауз и точного числа внешних тактов |
| PHY.MODES | CPOL/CPHA, ширина, полярность CS и геометрия FIFO задаются сборкой фиксированной PL |
| FIFO.BYTE_ORDER | Нет независимого управляемого SPI-ведомого для произвольных данных |
| FIFO.OVERFLOW | Нет управляемого потока RX/backpressure для проверки RX overflow и потери данных за границей full; TX full проверяется отдельно |
| BRAM.LIMIT_IRQ | Не определён однозначный контракт предупреждения за слово до границы BRAM |
| SD.FAULT_INJECTION | Нет управляемого источника задержек ответа/неверного CRC; reset-тест не доказывает восстановление после этих ошибок |
| REG.SD_INIT_LAYOUT | Противоречивые определения поля числа тактов требуют фиксации редакции спецификации |

Фиксированные конфигурации PL, независимый эталон и управляемые ошибки не
подменяются программными моделями в отчёте об аппаратном ядре. Граница
полноты отражается в SUMMARY: пропуски/блокировки дают INCOMPLETE, не PASS.
