# SD в PS и PL

В проекте есть два разных пути SD. Карта PS обслуживается файловым стеком
выбранной ОС. PL-узел текущего аппаратного профиля предоставляет только
последовательность инициализации карты. Этот раздел не описывает его как
блочный контроллер или файловый том.

## Текущий PL-контракт

Используются [bvstk_sd_init.c](../../../src/drivers/pl/sd/bvstk_sd_init.c)
и [bvstk_sd_init_regs.h](../../../src/hardware/pl/sd/bvstk_sd_init_regs.h).
Управляющее окно начинается с `0x43C50000`, ответы размещаются в общей
SPI BRAM с `0x44000000`. Встроенного окна секторов `0x100..0x10ff` этот
контракт не предоставляет.

| Смещение управления | Назначение |
|---:|---|
| `0x00` | CSR: сброс (бит 0), старт (бит 1), разрешение чтения (бит 2) |
| `0x04` | IRQ: `SOFT_DONE` (бит 0), `HARD_DONE` (бит 1) |
| `0x08` | Параметры пакета |
| `0x0C` | Аппаратное ожидание |
| `0x14` | Управление последовательностью SD |
| `0x18` | Сигнатура SPI-видимого узла |

Семь слов ответа находятся в BRAM со смещениями `0x00`, `0x04`, `0x08`,
`0x0C`, `0x10`, `0x14`, `0x18`: CMD0, две части CMD8, ACMD41, CMD55,
две части CMD58 соответственно. Смещения относятся к BRAM, а не
управляющему окну; одинаковые числа обозначают разные адреса.

Текущие константы последовательности: число тактов 100, делитель `0x0200`,
аппаратный тайм-аут 1, режим пакета `0x03`. Не путайте их с
`BVSTK_SD_CLOCK_DIV_DEFAULT=50`, сохранённым для другого блочного пути.
Общий номер IRQ 64 не означает использования прерывания: этот драйвер
проверяет регистр состояния опросом.

## Программный интерфейс

`bvstk_sd_init_init(driver, clock, mutex)` открывает окна и сохраняет
таблицы вызовов. `bvstk_sd_init_run(driver, timeout_ms, result)` запускает
последовательность и возвращает `bvstk_status_t`. Результат содержит
`irq`, `csr`, массив `response[7]`, признаки `hard_done` и `soft_done`.
Вызывающий хранит драйвер, контексты часов/mutex и результат до завершения.
Вызов выполняется из задачи/потока и может блокироваться.

Консоль FreeRTOS создаёт драйвер при первом обращении:

```text
sd-pl init 20000
```

Это операция с картой, не пассивный запрос состояния. Она не читает
файлы, не определяет готовность FatFs и не предоставляет форматирование.
Проверяйте статус и слова ответов; один установленный бит завершения
не доказывает поддержку дальнейших блочных команд.

## Сохранённый блочный путь

`bvstk_sd_controller.*`, порт `storage/sd-pl/` и файловая интеграция
сохранены для другого контракта. В текущем профиле
`CAN_BLOCK_IO=0`, `CAN_FILESYSTEM=0`, `AUTOSTART_FILESYSTEM=0`.
Описание другого RTL с базой `0x43C30000`, встроенным 4096-байтным буфером
и передачей до восьми секторов не применяется к установленному узлу.

Для его подключения недостаточно включить флаг. Нужны соответствующий
экспорт, регистровая карта, геометрия носителя, проверка чтения/записи и
ошибок, затем интеграция файловой системы. Испытание записи или
форматирования проводят только на специально выделенной карте с копией
нужных данных.

## PS SD

FreeRTOS использует свой дисковый слой FatFs. Штатный IFS Нейтрино
запускает `bvstk-sd-raw`, представляет FAT-область через
`/dev/bvstk-sd-fat` и подключает `devb-loopback` и DOS-файловую систему.
Этот путь не использует PL SD и не основан на `devb-sdmmc` в текущем IFS.
Схема и пользовательские пути приведены в
[хранении данных](../../system/storage.md).
