# drivers

[Карта исходников](../source-map.md)

Код [src/drivers](../../../src/drivers) выполняет операции с аппаратными
ядрами. Он знает порядок работы с регистрами и памятью, признаки
завершения и способы получения результата. Политики устройств и их
рабочий кэш находятся в [services](services.md).

Все текущие драйверы расположены в `drivers/pl`. Для доступа к аппаратуре
они используют общие интерфейсы MMIO, времени и блокировок; реализация
этих интерфейсов выбирается в [ports](ports.md).

## drivers/pl

Каталог разделён по аппаратному интерфейсу. Несколько файлов одной
подсистемы могут обслуживать разные ядра или разные версии их
регистрового интерфейса.

### drivers/pl/i2c

Ведущий драйвер запускает обмен с внешним устройством. Ведомый драйвер
получает запрос внешнего ведущего и подготавливает ответ в памяти PL.
Способ доставки IRQ средствами ОС находится в портах.

| Файл | Назначение |
|---|---|
| [bvstk_i2c_master.h](../../../src/drivers/pl/i2c/bvstk_i2c_master.h) | Определяет состояние ведущего драйвера и операции обмена массивами байтов, чтения и записи регистра. |
| [bvstk_i2c_master.c](../../../src/drivers/pl/i2c/bvstk_i2c_master.c) | Формирует команду и данные TX FIFO, ожидает результат опросом состояния, читает ответ из BRAM и восстанавливает ядро после ошибок. |
| [bvstk_i2c_slave.h](../../../src/drivers/pl/i2c/bvstk_i2c_slave.h) | Определяет состояние ведомого драйвера, снимок события IRQ и операции с принятым кадром и окном ответа. |
| [bvstk_i2c_slave.c](../../../src/drivers/pl/i2c/bvstk_i2c_slave.c) | Считывает состояние ведомого ядра и кадр из BRAM, записывает окно чтения, подтверждает подготовленный ответ и снимает аппаратные события. |

Последовательности обмена разобраны в
[описании драйверов I²C](../../system/pl-subsystem/i2c/drivers/drivers.md).

### drivers/pl/mdio

Один драйвер объединяет ведущую и ведомую стороны MDIO. Это соответствует
их работе через общую BRAM: ведущая сторона читает и записывает PHY,
ведомая принимает записи и использует опубликованные значения.

| Файл | Назначение |
|---|---|
| [bvstk_mdio_core.h](../../../src/drivers/pl/mdio/bvstk_mdio_core.h) | Объявляет доступ к ведущему ядру, чтение принятых ведомым ядром записей и публикацию значений для его ответов. |
| [bvstk_mdio_core.c](../../../src/drivers/pl/mdio/bvstk_mdio_core.c) | Выполняет обмены MDIO, обслуживает ячейки принятых записей в BRAM и подтверждает события ведомого ядра. |

Порядок обработки и ограничения аппаратного хранения запросов описаны
в [главе драйверов MDIO](../../system/pl-subsystem/mdio/drivers/drivers.md).

### drivers/pl/spi

Общий драйвер SPI работает с пакетами слов. Его наличие в исходниках
нужно отличать от подключения аппаратного ядра: в текущем описании платы
общий SPI отключён, а обмен с SD обслуживает специализированный драйвер
из соседнего каталога.

| Файл | Назначение |
|---|---|
| [bvstk_spi_core.h](../../../src/drivers/pl/spi/bvstk_spi_core.h) | Задаёт режим обмена, параметры тактирования и интерфейс передачи пакета с получением результата. |
| [bvstk_spi_core.c](../../../src/drivers/pl/spi/bvstk_spi_core.c) | Настраивает ядро SPI, загружает слова передачи, ожидает завершение и получает данные из BRAM. |

### drivers/pl/sd

Основной действующий путь — `bvstk_sd_master`: команды карты передаются
через SPI master, данные блоков — через DMA и BRAM. ОС предоставляет
ему обработку событий и барьеры памяти. Сервис SD над этим драйвером
управляет состоянием карты и операциями по секторам.

Два других модуля описывают самостоятельные интерфейсы: запуск
аппаратной инициализации и регистровый контроллер блочного обмена.
Выбирать файл следует по подключённому аппаратному интерфейсу.

| Файл | Назначение |
|---|---|
| [bvstk_sd_master.h](../../../src/drivers/pl/sd/bvstk_sd_master.h) | Определяет параметры SPI master, DMA и BRAM, функции событий ОС и отчёт о выполненной команде SD. |
| [bvstk_sd_master.c](../../../src/drivers/pl/sd/bvstk_sd_master.c) | Инициализирует карту, кодирует команды, запускает DMA, проверяет ответы и CRC, сохраняет состояние ошибки перед восстановлением. |
| [bvstk_sd_init.h](../../../src/drivers/pl/sd/bvstk_sd_init.h) | Объявляет запуск аппаратной последовательности инициализации и структуру снимка её результатов. |
| [bvstk_sd_init.c](../../../src/drivers/pl/sd/bvstk_sd_init.c) | Настраивает и запускает инициализатор SD, ожидает его завершение и считывает ответы из памяти. |
| [bvstk_sd_controller.h](../../../src/drivers/pl/sd/bvstk_sd_controller.h) | Задаёт интерфейс отдельного регистрового контроллера SD, включая чтение и запись секторов и способ ожидания завершения. |
| [bvstk_sd_controller.c](../../../src/drivers/pl/sd/bvstk_sd_controller.c) | Передаёт блоки через окно данных этого контроллера, разбивает большие запросы на порции и проверяет состояние операции. |

Текущий путь SD разобран в
[главе драйверов SPI и SD](../../system/pl-subsystem/spi/drivers/drivers.md).
