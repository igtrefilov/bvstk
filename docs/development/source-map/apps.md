# apps

[Карта исходников](../source-map.md)

В [src/apps](../../../src/apps) определены состав программ и их
пользовательские интерфейсы. Приложение создаёт экземпляры общих
модулей, связывает их с портом ОС и принимает внешние команды.
Поэтому здесь встречаются зависимости от всех основных частей дерева.

## apps/freertos

Одна программа объединяет рабочие экземпляры подсистем, сетевые
обработчики, консоли и файловое обслуживание. Задачи создаются из
общей точки запуска. Вложенные каталоги разделяют конфигурацию,
рабочую среду, команды, внешние интерфейсы и работу с файлами.

[Каталоги и файлы приложения FreeRTOS](apps/freertos.md).

## apps/neutrino

Несколько программ выполняют разные роли. `bvstkd` владеет рабочей
средой I²C и принимает запросы; командный клиент обращается к ней через
IPC. Оболочка и утилита доступа к PL имеют собственные точки входа.
Один вложенный каталог может содержать исходники для нескольких
исполняемых файлов.

[Каталоги и файлы приложений Нейтрино](apps/neutrino.md).

## Подключение исходников

Состав программы определяется сборочными сценариями.
[Сборка FreeRTOS](../../../scripts/vitis/build.tcl) выбирает ветвь
`apps/freertos`, общие исходники и порт `freertos-xilinx`.
[Сборка Нейтрино](../../../scripts/neutrino/build.sh) перечисляет
исходники для каждой программы отдельно.

Наличие файла в выбранной ветви ещё не означает запуск его функций.
В подробных главах отмечены оставшиеся в дереве обработчики, которые
текущий код запуска не подключает. Действующие возможности двух целей
сведены в [вариантах системы](../../system/architecture/variants.md).
