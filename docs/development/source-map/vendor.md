# vendor

[Карта исходников](../source-map.md)

[src/vendor](../../../src/vendor) содержит включённые в проект исходники
сетевых компонентов lwIP. Прикладные обработчики, которые используют
эти компоненты, находятся в [приложении FreeRTOS](apps/freertos.md).

## vendor/lwip

Здесь размещены MQTT и SNTP, а также код DNS. Основной сетевой стек
и его порт для платы приходят из BSP. Поэтому этот каталог содержит
часть используемых сетевых исходников.

### vendor/lwip/mqtt

Клиент MQTT: соединение с брокером, публикация сообщений, подписки
и обработка ответов. Параметры конкретного подключения задаёт
`apps/freertos/services/mqtt/mqtt_processing.c`.

| Файл | Назначение |
|---|---|
| [mqtt.h](../../../src/vendor/lwip/mqtt/mqtt.h) | Объявляет клиент MQTT, параметры подключения и функции публикации, подписки и приёма сообщений. |
| [mqtt.c](../../../src/vendor/lwip/mqtt/mqtt.c) | Кодирует и разбирает сообщения MQTT, ведёт соединение, ожидающие запросы, подтверждения и таймеры. |
| [mqtt_priv.h](../../../src/vendor/lwip/mqtt/mqtt_priv.h) | Определяет внутреннее состояние клиента, очередь запросов и буфер вывода. |
| [mqtt_opts.h](../../../src/vendor/lwip/mqtt/mqtt_opts.h) | Задаёт параметры компиляции клиента: размеры буферов, пределы ожидающих запросов и интервалы обработки. |

### vendor/lwip/sntp

Клиент времени SNTP и расположенный рядом преобразователь имён DNS.
В SNTP есть дополнение проекта: привязка полученного времени к таймеру
процессора для последующего вычисления времени в микросекундах.

| Файл | Назначение |
|---|---|
| [sntp.h](../../../src/vendor/lwip/sntp/sntp.h) | Объявляет запуск и остановку SNTP, настройку серверов и получение вычисленного времени. |
| [sntp.c](../../../src/vendor/lwip/sntp/sntp.c) | Отправляет запросы времени, обрабатывает ответы и повторные попытки, сохраняет привязку времени сервера к локальному таймеру. |
| [sntp_opts.h](../../../src/vendor/lwip/sntp/sntp_opts.h) | Задаёт режимы и параметры компиляции SNTP: интервалы запросов, проверки ответов и способы выбора серверов. |
| [dns.h](../../../src/vendor/lwip/sntp/dns.h) | Объявляет настройку DNS-серверов и асинхронное разрешение имени в IP-адрес. |
| [dns.c](../../../src/vendor/lwip/sntp/dns.c) | Ведёт DNS-кэш, отправляет запросы, проверяет ответы и вызывает обработчик результата разрешения имени. |

В текущем коде запуска `mqtt_init()` и `time_sync_task()` не вызываются.
Наличие этих исходников в сборочном дереве само по себе не запускает
подключение к брокеру или синхронизацию времени.
