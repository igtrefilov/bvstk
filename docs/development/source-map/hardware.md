# hardware

[Карта исходников](../source-map.md)

[src/hardware](../../../src/hardware) содержит описание аппаратуры,
которое использует программа PS: адреса областей, номера прерываний,
регистры и признаки наличия ядер. HDL самих ядер находится в аппаратном
проекте. Здесь разделены сведения о подключении устройств на плате
и регистровые интерфейсы отдельных ядер.

## hardware/boards

Описания плат. В текущем дереве представлена плата AX7020.

### hardware/boards/ax7020

Общее аппаратное описание для двух ОС. Драйверы используют эти сведения,
а порт FreeRTOS дополнительно сверяет их с заголовками, созданными
из аппаратного экспорта.

| Файл | Назначение |
|---|---|
| [bvstk_hw_config.h](../../../src/hardware/boards/ax7020/bvstk_hw_config.h) | Задаёт адреса и размеры областей PL, номера IRQ, доступные ядра и параметры подключения SD. |
| [bvstk_pl_regions.h](../../../src/hardware/boards/ax7020/bvstk_pl_regions.h) | Определяет идентификаторы и описание именованных регионов, а также операции их поиска. |
| [bvstk_pl_regions.c](../../../src/hardware/boards/ax7020/bvstk_pl_regions.c) | Собирает адреса из аппаратной конфигурации в таблицу регионов и предоставляет поиск по имени или идентификатору. |
| [bvstk_qspi_layout.h](../../../src/hardware/boards/ax7020/bvstk_qspi_layout.h) | Определяет геометрию QSPI и окно файловой системы. Проверяет согласованность границ окна при компиляции. |

`bvstk_pl_regions.c` описывает адресное пространство; доступ к этим
регионам выполняет модуль `shared/pl/access`. Сверка адресов с BSP
находится в `ports/freertos-xilinx/board/ax7020` — см.
[описание порта](ports.md).

## hardware/pl

Регистровые интерфейсы ядер. Эти заголовки позволяют драйверу обращаться
к регистрам по именам. При изменении интерфейса ядра сначала требуется
согласовать его описание здесь, затем использующий его драйвер.

### hardware/pl/i2c

| Файл | Назначение |
|---|---|
| [bvstk_i2c_regs.h](../../../src/hardware/pl/i2c/bvstk_i2c_regs.h) | Задаёт регистры ведущего и ведомого ядер, признаки состояния и событий, размещение окон обмена в BRAM. |

### hardware/pl/mdio

| Файл | Назначение |
|---|---|
| [bvstk_mdio_regs.h](../../../src/hardware/pl/mdio/bvstk_mdio_regs.h) | Определяет смещения регистров ведущего и ведомого ядер MDIO. |

### hardware/pl/spi

| Файл | Назначение |
|---|---|
| [bvstk_spi_regs.h](../../../src/hardware/pl/spi/bvstk_spi_regs.h) | Определяет регистры и режимы пакетного обмена общего драйвера SPI. |

### hardware/pl/sd

В каталоге сохранены описания нескольких аппаратных интерфейсов SD.
Для текущего пути через SPI master и DMA используется
`bvstk_sd_master_regs.h`. Остальные заголовки нужны соответствующим
драйверам, которые имеют другой способ управления аппаратурой.

| Файл | Назначение |
|---|---|
| [bvstk_sd_master_regs.h](../../../src/hardware/pl/sd/bvstk_sd_master_regs.h) | Описывает регистры SPI master и DMA, ячейки ответов и области передачи блоков в BRAM. |
| [bvstk_sd_init_regs.h](../../../src/hardware/pl/sd/bvstk_sd_init_regs.h) | Задаёт команды запуска аппаратной инициализации SD, события завершения и размещение ответов на команды карты. |
| [bvstk_sd_regs.h](../../../src/hardware/pl/sd/bvstk_sd_regs.h) | Описывает отдельный регистровый контроллер блочного ввода-вывода: команду, номер сектора, окно данных и состояние. |

Соответствие этих интерфейсов исходникам объяснено в
[каталоге драйверов](drivers.md). Возможности подключённых вариантов
перечислены в [вариантах системы](../../system/architecture/variants.md).
