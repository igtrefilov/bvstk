# Диагностика

Начинайте с наблюдаемого отказа и выбранного профиля. Неисправность
не подтверждается отсутствием функции, которая в этой сборке не включена.
До сброса сохраните журнал и сведения о загруженных файлах. Запись MMIO,
изменение политики и форматирование не являются читающими проверками.

## Сначала локализовать отказ

| Наблюдение | Первая проверка | Следующий шаг |
|---|---|---|
| Нет начала загрузки по UART | Порт, скорость, единственный читатель, питание | Сопоставить bitstream, PS7 initialization и ELF/IFS |
| UART работает, сеть нет | Адрес выбранной ОС, кабель, подсеть, состояние интерфейса | [Сетевая диагностика](network.md) |
| DCP2 PING проходит, FS отвергается | Какая ОС загружена | В Нейтрино использовать SSH; во FreeRTOS запросить INFO |
| `FS not ready` | Нужный том и журнал монтирования | Проверить носитель и доступный файловый стек |
| Нет `sd-pl:/` | `CAN_FILESYSTEM=0` в текущем профиле | Это ожидаемое ограничение, не повод форматировать карту |
| `I2C not ready` | Список конфигураций, стадия запуска службы | Проверить тайм-аут инициализации и журнал |
| В Нейтрино нет `/dev/bvstk-i2c` | Запустился ли `bvstkd` | Проверить его конфигурацию, MMIO и IRQ |
| SMI/SPI недоступны | Признаки `HAS_*` | В текущем профиле выключены; не повторять запрос бесконечно |
| Запись отклонена | Диапазон и политика выбранного устройства | Сравнить правила; не отключать защиту для пробного теста |
| I²C завершился по тайм-ауту | Совместимость PL, адрес устройства, линии, тактирование | Разделить ведущий запрос и ведомый IRQ-путь |
| Настройка исчезла после перезапуска | Результат сохранения и фактический JSON | [Жизненный цикл конфигурации](../system/configuration.md) |
| HTTP 200, но JSON не разбирается | Маршрут и полное тело | Учесть ограничение `/api/i2c?name=...` в справочнике |
| Копирование дерева оборвалось | Код клиента, изменение исходника, состояние тома | Сохранить старую копию и начать новое чтение |

## Не смешивать уровни успеха

Открытый TCP-порт подтверждает только слушающую службу. HTTP 200 может
содержать `saved:false`. Сообщение инициализации SD не подтверждает доступ
к секторам. Отпечаток нового ELF не подтверждает, что именно он загружен.
Проверка должна доходить до результата нужной операции.

При смене IP сначала проверьте новый адрес, затем старый и локальный
интерфейс. Не повторяйте изменяющий запрос только потому, что ответ
потерялся. При ошибке записи устройства выясните, могла ли операция
завершиться до обрыва связи; повтор может иметь побочный эффект.

## Что приложить к сообщению об отказе

Укажите модель платы, выбранную ОС, ревизии BVSTK и аппаратуры, локальные
изменения, версии инструментов и суммы загруженных файлов. Приведите точную
команду, ожидаемый результат, фактический код/ответ и журнал с момента
запуска нужной службы. Для файлов укажите том и путь, для I²C — имя,
адрес и регистр. Не прикладывайте пароли, приватные ключи и содержимое
секретных файлов.

Повторяемую неисправность отделяйте от непроверенного предположения о её
причине. Правила подготовки теста и фиксации свидетельств находятся в
[руководстве разработчика](../development/testing.md).
