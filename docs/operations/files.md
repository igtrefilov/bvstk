# Работа с файлами

В текущем FreeRTOS доступны `flash:/` и `sd:/`; в Нейтрино — `/flash` и
`/sd`. PL SD не предоставляет файловую систему. На готовность нужного
тома указывает ответ файловой операции или диагностического API, а не
само наличие Ethernet-соединения.

## Прочитать конфигурацию FreeRTOS

В консоли можно перечислить каталог и вывести текстовый файл:

```text
ls flash:/config
ls flash:/config/i2c
cat flash:/config/network.json
```

Для внешнего скрипта предпочтительнее DCP2 FS. Он не требует разбирать
текстовые ответы консоли:

```sh
python3 scripts/dcp2/monitor_notify.py 192.168.0.10 \
  --fs-list flash:/config/ --recursive
python3 scripts/dcp2/monitor_notify.py 192.168.0.10 \
  --fs-tar flash:/config/ --output config-backup.tar
tar -tf config-backup.tar
```

Первая команда возвращает имена и размеры, вторая — содержимое файлов и
каталоги в архиве. Существующий локальный `config-backup.tar` заменяется
после успешного завершения чтения; заранее выберите новое имя, если старую
копию нужно сохранить. Полное поведение результата и ошибок описано в
[практике DCP2](dcp2.md).

На время резервного копирования прекратите изменения дерева через консоль,
HTTP и другие клиенты. TAR не является атомарным снимком. Код завершения
клиента и успешное чтение списка архива проверяют раздельно.

## Копировать между томами

В консоли FreeRTOS сначала создайте каталог назначения, затем копируйте:

```text
mkdir sd:/backup
cp flash:/config/network.json sd:/backup/network.json
cat sd:/backup/network.json
```

Путь с префиксом выбирает том явно. Относительный путь зависит от текущего
каталога сеанса; в автоматизации лучше использовать полный путь. Семантика
рекурсивного копирования, перемещения и удаления приведена в
[командах файлового слоя](../reference/console-commands.md#файлы-и-каталоги).

## SSH и SFTP

При включённом FreeRTOS SSH виртуальные корни `/flash:/` и `/sd:/`
соответствуют FatFs. Пример чтения:

```sh
scp root@192.168.0.10:/flash:/config/network.json ./network.json
```

Для классического SCP используется `scp -O`; современный клиент обычно
использует SFTP. Для каталога добавляют `-r`. Явно выбирайте том: путь без
префикса может разрешиться относительно другого корня сеанса.
FatFs не предоставляет Unix-владельцев, символические ссылки и полный
набор POSIX-метаданных.

В Нейтрино используйте пути ОС и соответствующий IFS-ключ:

```sh
scp -i build/neutrino/ax7020_ssh_client -r \
  root@192.168.0.10:/flash/config ./neutrino-config-backup
```

Проверяйте, куда клиент поместил каталог, особенно если локальная цель уже
существует. Копия FreeRTOS `network.json` может лежать на общем QSPI-томе,
но штатная сеть Нейтрино не обязана её использовать.

## Загрузка и восстановление

DCP2 FS предоставляет чтение. Для записи FreeRTOS доступны HTTP, SCP/SFTP
и файловые команды. Перед восстановлением сохраните нынешний набор,
проверьте JSON на компьютере и наличие свободного места. HTTP-загрузка
усекает целевой файл; при обрыве он может остаться неполным. Она не
обеспечивает атомарную замену всего дерева или откат.

После загрузки прочитайте файл обратно и сравните содержимое. Прямая
замена JSON не обновляет автоматически модель работающих сервисов. Планируйте
контролируемый перезапуск и проверку списка устройств и правил.

Не форматируйте QSPI или SD как первый шаг восстановления. Форматирование
уничтожает файловую систему; JTAG-перезапуск также может прервать текущую
запись. Устройство носителей и границы QSPI описаны в
[хранении данных](../system/storage.md).
