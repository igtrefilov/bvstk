# Работа через HTTP

HTTP доступен во FreeRTOS. Сервер обслуживает состояние устройства,
настройки, файлы и статические страницы. Аутентификации и TLS в этом
интерфейсе нет; используйте доверенную сеть. Контракты полей и ошибок
находятся в [справочнике HTTP](../reference/http-api.md).

## Проверить состояние

```sh
curl -fsS http://192.168.0.10/api/version
curl -fsS http://192.168.0.10/api/rtos
curl -fsS http://192.168.0.10/api/net
curl -fsS http://192.168.0.10/api/fs
curl -fsS http://192.168.0.10/api/i2c
```

Ключ `-f` позволяет отличить HTTP-ошибку по коду завершения `curl`, но
не проверяет содержимое JSON. Например, готовность тома и успешность
сохранения передаются отдельными полями.

Запрос конфигурации одного устройства `/api/i2c?name=...` имеет известную
ошибку формирования JSON. Для надёжного чтения полного документа используйте
файловый путь или DCP2 FS:

```sh
curl -fsS http://192.168.0.10/flash/config/i2c/axp15060.json
```

## Прочитать файл или дерево

Для файла URL `/flash/...` выбирает QSPI, `/sd/...` — PS SD. Корень `/`
обслуживает веб-ресурсы, а не список всех томов.

```sh
curl -fS -o network.json http://192.168.0.10/flash/config/network.json
curl -fS -o config.tar http://192.168.0.10/tar/flash/config
tar -tf config.tar
```

`curl -o` может оставить частичный локальный файл при обрыве. Проверяйте
код завершения и архив; не заменяйте единственную резервную копию этим
непроверенным результатом. Если нужна замена локальной цели только после
успешного чтения, используйте `--output` [клиента DCP2](dcp2.md).

## Загрузить файл

Создайте каталог назначения в консоли, затем отправьте файл. Пример
перезаписывает `flash:/config/network.json`:

```sh
curl -fS --upload-file ./network.json \
  http://192.168.0.10/flash/config/network.json
```

Метод загрузки — `PUT`, не `POST`. Обработчик пишет прямо в целевой файл.
При ошибке нет гарантии сохранения предыдущего содержимого. Прочитайте
файл обратно, сравните его с исходником и лишь затем планируйте перезапуск.
Загрузка JSON не является применением конфигурации работающего сервиса.

Для каталога поддерживается `PUT /tar/flash/<каталог>` или
`PUT /tar/sd/<каталог>` с TAR. Распаковка может перезаписать совпадающие
файлы и не является транзакцией. Перед массовым восстановлением нужна
резервная копия и проверенный состав архива.

Изменение сети с немедленным применением вынесено в
[отдельную процедуру](network.md), поскольку ответ может потеряться при
смене адреса. Диагностические записи MMIO и перезапуск не относятся к
проверке связи и не должны выполняться как пробный запрос.
