# Работа с устройством

Начните с определения загруженной сборки: FreeRTOS и Нейтрино предоставляют
разные оболочки и сетевые службы. Далее используются адрес `192.168.0.10`
и штатные порты. Замените адрес фактическим; сохранённая конфигурация может
отличаться от исходной. Подключайте устройство к доверенной инженерной сети.

## Первое подключение к FreeRTOS

Проверьте сетевое соединение, затем откройте TCP-консоль:

```sh
nc 192.168.0.10 8888
```

В консоли выполните только читающие команды:

```text
help
ip addr show
pwd
ls flash:/
i2c list
```

На компьютере проверьте HTTP и DCP2:

```sh
curl -fsS http://192.168.0.10/api/version
curl -fsS http://192.168.0.10/api/fs
python3 scripts/dcp2/monitor_notify.py 192.168.0.10 --ping
```

Ответ одной службы не подтверждает готовность остальных. Если том ещё не
готов, разберите журнал монтирования; не запускайте форматирование для
исправления неизвестной ошибки. SSH будет доступен только в
[сборке с SSH](../build/freertos.md).

## Первое подключение к Нейтрино

Используйте клиентский ключ, соответствующий загруженному IFS:

```sh
ssh -i build/neutrino/ax7020_ssh_client root@192.168.0.10
```

При первом подключении проверьте отпечаток ключа устройства по доверенному
каналу. В оболочке устройства:

```sh
bvstkctl version
ls -l /dev/bvstk-i2c
i2c list
ls /flash/config/i2c
ls /sd
```

Отсутствие HTTP или TCP-консоли `8888` в этом варианте ожидаемо. DCP2 FS
также не подключён: для файлов используйте SSH/SFTP и пути `/flash`, `/sd`.
Подробные различия собраны в [таблице возможностей](../reference/profiles.md).
