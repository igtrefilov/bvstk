# Справочник

Здесь находятся точные имена, поля, диапазоны и ограничения. Рабочие
сценарии вынесены в [руководство по эксплуатации](../operations/README.md),
механизмы — в [устройство системы](../system/README.md).

- [Возможности сборок](profiles.md): ОС, службы, порты и включённые узлы.
- [Плата AX7020](board.md): MMIO, BRAM, IRQ и границы сведений о сигналах.
- [Конфигурация](configuration.md): JSON, обязательные поля, пределы и различия парсеров.
- [Консольные команды](console-commands.md): синтаксис, ответы и побочные действия.
- [HTTP API](http-api.md): методы, запросы, результаты и ограничения реализации.
- [Коды результатов](status-codes.md): различия ошибок C API, HTTP, консоли и DCP2.
- [Параметры сборки](build-options.md): входы сценариев, приоритеты и результаты.

[Спецификация DCP2](../dcp2/dcp2.md) сопровождается отдельно. Эта версия
документации не меняет её содержимое и не создаёт второй формальный
справочник кадров. Готовый клиент описан в [практике DCP2](../operations/dcp2.md).
