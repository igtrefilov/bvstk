# Файлы конфигурации

Справочник описывает JSON, который загружают программы BVSTK, и отдельно
отмечает ограничения текущих парсеров. Это не описание полей HTTP-запроса:
например, сетевой файл содержит объект `ipv4`, а HTTP PUT принимает плоский
набор полей. Порядок выбора источника и применение описаны в
[жизненном цикле конфигурации](../system/configuration.md).

## Размещение и общие правила

| Данные | Исходник для встроенного набора | Основной путь FreeRTOS | Основной путь Нейтрино |
|---|---|---|---|
| Сеть | `configs/network.json` | `flash:/config/network.json` | Не используется для настройки сети штатного IFS |
| I²C | `configs/i2c/*.json` | `flash:/config/i2c/` | `/flash/config/i2c/` |
| SMI | `configs/smi/*.json` | `flash:/config/smi/` | Загрузчик SMI не подключён |

Старые каталоги имеют имя `configs` вместо `config`. Изменение файла на
носителе не является командой немедленного применения. Генератор
`tools/codegen/gen_default_configs.py` обновляет встроенный набор во время
сборки; сохранённые файлы устройства имеют собственный жизненный цикл.

Записывайте корректный JSON без комментариев, повторяющихся ключей и
неизвестных расширений. Целые числа в новых файлах задавайте десятичными
JSON-числами, логические значения — `true`/`false`. Парсеры допускают
некоторые дополнительные формы, включая числовые строки, но не являются
полной реализацией проверки JSON: поиск ключей не контролирует всё дерево,
а обработка экранирования ограничена. Не используйте `\uXXXX` для имён.
Для совместимых имён устройств и файлов выбирайте буквы ASCII, цифры,
дефис и подчёркивание; суффикс файла — `.json`.

Нельзя использовать терпимость парсера как контракт. Во FreeRTOS некоторые
массивы при разборе ограничиваются вместимостью, а числовые значения
сужаются до ширины поля до последующей проверки. Нейтрино использует другой,
более строгий I²C-кодек. Файлы с превышенными пределами не являются
переносимыми между сборками, даже если одна из них их приняла.

## Сеть FreeRTOS

Полный исходный набор:

```json
{
  "ipv4": {
    "ip": "192.168.0.10",
    "netmask": "255.255.255.0",
    "gateway": "192.168.0.1"
  },
  "mac": "00:0a:35:00:01:02"
}
```

| Поле | Тип | Условие |
|---|---|---|
| `ipv4.ip` | Строка | IPv4, четыре десятичных октета `0..255`, без префикса CIDR |
| `ipv4.netmask` | Строка | Четыре октета; семантическую пригодность маски проверяет автор файла |
| `ipv4.gateway` | Строка | IPv4 шлюза |
| `mac` | Строка | Шесть шестнадцатеричных октетов через двоеточие |

Все четыре значения нужны для полного файла. Загрузчик сначала задаёт
встроенные значения и отмечает наличие корректно прочитанных полей;
неполный или повреждённый файл не следует использовать как поддерживаемый
способ частичного обновления. Парсер находит имена полей текстовым поиском,
поэтому не проверяет строго вложенность `ipv4`. Новые файлы должны
соблюдать показанную структуру, которую записывает сам проект.

Текущий старт FreeRTOS использует статическую конфигурацию. Поля HTTP
`mode` и `dhcp` описывают состояние сборки lwIP, но в этом JSON нет
настройки включения DHCP. Нейтрино задаёт сеть через сценарий IFS.

## Устройство I²C

```json
{
  "name": "axp15060",
  "addr_7b": 54,
  "reg_count": 74,
  "max_value_code": 64,
  "policy": "whitelist",
  "whitelist": [{"reg": 19, "val": 16}],
  "blacklist": [],
  "settings": []
}
```

Пример показывает форму файла, а не разрешение записывать выбранный
регистр на любом оборудовании.

| Поле | Тип | Обязательность и предел |
|---|---|---|
| `name` | Строка | Обязательно, непустое имя; до 31 байта плюс завершающий ноль в модели C |
| `addr_7b` | Целое | Обязательно, `0..127`; адрес без бита направления |
| `reg_count` | Целое | Обязательно, `1..256`; число регистров, не последний индекс |
| `max_value_code` | Целое | Обязательно, `0..64` в текущих загрузчиках |
| `policy` | Строка | Обязательно, `whitelist` или `blacklist` |
| `whitelist` | Массив объектов | Необязательно, по умолчанию пуст; до 256 пар |
| `blacklist` | Массив объектов | Необязательно, по умолчанию пуст; до 256 пар |
| `settings` | Массив объектов | Необязательно, по умолчанию пуст; до 256 пар |

Элемент списков имеет поля `reg` и `val`. Для правил `reg` находится в
`0..reg_count-1`, `val` — в `0..max_value_code`. Политика белого списка
разрешает только перечисленные пары, чёрного — всё в допустимом диапазоне,
кроме перечисленных пар. Пустой белый список запрещает запись; пустой
чёрный список не запрещает её дополнительно к проверке диапазона.

В `settings` номер регистра также меньше `reg_count`, но сохранённое
значение — байт `0..255`: загрузчики не ограничивают его полем
`max_value_code`. Это важно для значений, прочитанных с оборудования.
Инициализация кэша из `settings` не должна описываться как безусловная
серия физических записей во все регистры.

`file_name` — служебное поле структуры C, которое заполняет загрузчик по
имени файла. Это не обязательное поле JSON и не команда выбора произвольного
пути для сохранения. Вместимость — 48 байт, то есть не более 47 байт имени.
Нейтрино дополнительно принимает в имени файла только ASCII-буквы, цифры,
`_`, `-`, `.` и суффикс `.json`. Максимум устройств — 32.

Для совместимости держите размер I²C-файла меньше 16384 байт: FreeRTOS
читает в буфер на 16384 байта с местом для завершающего нуля. Превышение
не является гарантированно диагностируемой ошибкой полного документа.
Нейтрино допускает входной файл до 32768 байт. Наличие памяти под все
256 элементов каждого массива не означает, что любой красиво
отформатированный набор этих массивов поместится в файловый буфер.

Полей `autopoll_*` у I²C нет. Ограничения общей модели находятся в
[bvstk_config_model.h](../../src/shared/config/bvstk_config_model.h);
I²C-кодек Нейтрино — в
[bvstk_i2c_config_codec.c](../../src/shared/config/bvstk_i2c_config_codec.c).

## PHY SMI

Формат сохранён для реализации SMI во FreeRTOS. Наличие JSON не включает
SMI в текущем аппаратном профиле и не создаёт задачу периодического опроса.

```json
{
  "name": "lan8720",
  "phy_addr": 1,
  "reg_count": 32,
  "policy": "whitelist",
  "autopoll_enabled": true,
  "autopoll_reg_delay_ms": 0,
  "autopoll_cycle_delay_ms": 1000,
  "autopoll_regs": [0, 1, 4, 5, 17, 31],
  "write_allow_regs": [0, 4, 18, 30, 31],
  "write_deny_regs": [],
  "settings": []
}
```

| Поле | Тип | Обязательность, предел, умолчание |
|---|---|---|
| `name` | Строка | Обязательно, непустое; до 31 байта |
| `phy_addr` | Целое | Обязательно, `0..31` |
| `reg_count` | Целое | Обязательно, `1..32` |
| `policy` | Строка | Обязательно, `whitelist` или `blacklist` |
| `autopoll_enabled` | Логическое | Необязательно; `false` |
| `autopoll_reg_delay_ms` | Целое | Необязательно; `0..4294967295` мс, умолчание `0` |
| `autopoll_cycle_delay_ms` | Целое | Необязательно; тот же диапазон мс, умолчание `1000` |
| `autopoll_regs` | Массив целых | Необязательно; до 32 регистров, пуст по умолчанию |
| `write_allow_regs` | Массив целых | Необязательно; до 32 регистров, пуст по умолчанию |
| `write_deny_regs` | Массив целых | Необязательно; до 32 регистров, пуст по умолчанию |
| `settings` | Массив `{reg,val}` | Необязательно; до 32 пар, пуст по умолчанию |

Каждый регистр меньше `reg_count`. Значение SMI в `settings` имеет
диапазон `0..65535`. Политика SMI относится к номеру регистра, не к
паре «регистр, значение». Максимум PHY — 8; служебное имя файла имеет
вместимость 48 байт. Буфер сериализации SMI во FreeRTOS — 8192 байта.

`autopoll_enabled` и задержки задают параметры опроса, но его циклический
вызов обязан организовать код приложения. Текущий `bvstk_runtime` не
планирует такой цикл. Подробнее — в [главе SMI](../development/drivers/smi.md).

## Проверка файла

На компьютере можно проверить стандартный синтаксис:

```sh
python3 -m json.tool network.json
```

Это не проверяет пределы BVSTK и политику конкретного устройства. После
загрузки сравните файл, список устройств и правила в памяти, затем повторите
проверку после перезапуска. Для изменения сети или записи регистра
используйте соответствующую процедуру: правка файла не заменяет вызов сервиса.

Особенности загрузки FreeRTOS подтверждаются
[config_store.c](../../src/apps/freertos/config/config_store.c),
Нейтрино — [его загрузчиком](../../src/apps/neutrino/config/bvstk_i2c_config_store.c).
