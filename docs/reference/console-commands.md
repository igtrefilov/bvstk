# Консольные команды

Команды FreeRTOS доступны через TCP-консоль и включённый в сборку SSH.
Обычные команды I²C также доступны в Нейтрино как программа `i2c` и через
`bvstkctl i2c`. Файловые и сетевые команды Нейтрино — средства ОС, а не
диспетчер FreeRTOS.

## Синтаксис и ответы

В записи ниже `<аргумент>` обязателен, `[аргумент]` необязателен; скобки
не вводятся. Числа обычно принимаются десятичными или с префиксом `0x`.
Для IPv4, MAC и именованных режимов действуют отдельные форматы.
Диспетчер FreeRTOS разбивает строку по пробелам и табуляциям: полноценное
экранирование и кавычки Unix-оболочки для путей с пробелами не гарантируются.

`help` выводит общую справку; `fs` — справку файлового слоя.
`quit` и `exit` закрывают сеанс. Команда, выводящая данные, не обязана
заканчиваться отдельным `OK`; текстовый интерфейс не предназначен для
побайтово стабильного машинного разбора.

| Маркер | Значение |
|---|---|
| `OK` | Основная операция выполнена |
| `ERR` | Ошибка аргументов или выполнения; уточнение может следовать в той же строке |
| `ERR DENIED`, `DENIED` | Отказ по диапазону или политике |
| `FS not ready`, `I2C not ready` | Нужная подсистема не готова |
| `WARN` | Вспомогательное действие, например сохранение, не завершилось |

## Файлы и каталоги

Только диспетчер FreeRTOS. Рабочий каталог принадлежит сеансу. Префиксы
`sd:/` и `0:/` выбирают PS SD, `flash:/` и `1:/` — QSPI. Формы
`sd/`, `flash/` также распознаются маршрутизатором; для скриптов лучше
полные имена с двоеточием. `cd flash` и `cd sd` переключают том.
Абсолютный путь без имени тома относится к текущему тому.

| Синтаксис | Результат и побочные действия |
|---|---|
| `pwd` | Текущий каталог сеанса |
| `ls [path]` | Непосредственное содержимое каталога; без пути — текущего |
| `cd <path>` | Проверяет каталог и меняет состояние сеанса |
| `mkdir <path>` | Создаёт каталог |
| `touch <path>` | Создаёт файл; существующий усекает до нуля |
| `fs write <path> <text>` | Создаёт/заменяет текстовый файл; остаток строки пишется буквально, без автоматического перевода строки |
| `fs append <path> <text>` | Дописывает текст в конец файла; создаёт отсутствующий файл |
| `cat <path>` | Передаёт содержимое файла в консоль |
| `rm <path>` | Удаляет файл или пустой каталог |
| `rm -r <path>` | Рекурсивно удаляет дерево без корзины |
| `cp <src> <dst>` | Копирует файл; совпадающая цель может быть заменена |
| `cp -r <src> <dst>` | Копирует дерево |
| `mv <src> <dst>` | Переименовывает или переносит объект |

Если `dst` — существующий каталог, `cp` и `mv` добавляют к нему базовое
имя источника. Между томами используются операции копирования/переноса
файлового слоя, а не атомарное переименование. Ошибка может оставить
частичную цель; до удаления исходника проверьте результат. Сбой файловой
операции не гарантирует откат.

`sd-pl:/` (внутреннее имя `2:/`) — существующий FAT-том внешней карты через
PL SPI/DMA. Инициализация и монтирование автоматические при старте.
`cd sd-pl` переключает текущий том. `fs format sd-pl confirm` запрещена,
как и скрытое автоматическое форматирование при отсутствии файловой системы.
При ошибке монтирования проверьте UART-журнал и используйте уже подготовленную
карту FAT12/16/32. Для QSPI и PS SD эта команда форматирования не предоставляет.

## Архивы

Только FreeRTOS:

| Синтаксис | Действие |
|---|---|
| `tar c <src_dir> <dst_tar>` | Создаёт TAR каталога в файле |
| `tar t <src_tar>` | Перечисляет архив |
| `tar x <src_tar> <dst_dir>` | Извлекает файлы в каталог, может заменить существующие |

Создание и извлечение не образуют транзакцию. Не размещайте создаваемый
архив внутри копируемого дерева. Для резервной копии на компьютере
используйте [DCP2 FS](../operations/dcp2.md).

## Сеть

Только FreeRTOS; команды показывают или изменяют работающий `netif`.

| Синтаксис | Действие |
|---|---|
| `ip addr show` | IP, префикс, маска и шлюз |
| `ip addr set <IPv4>/<prefix>` | Применяет IP/маску и пытается сохранить набор |
| `ip link show` | MAC-адрес |
| `ip link set address <mac>` | Обновляет MAC в программной конфигурации интерфейса и сохраняет |
| `ip route show` | Шлюз по умолчанию |
| `ip route set default via <IPv4>` | Применяет и сохраняет шлюз |
| `ip save` | Сохраняет текущие параметры интерфейса |

IPv4 задают четырьмя октетами, префикс — `0..32`, MAC — шестью
шестнадцатеричными октетами через двоеточие. Сохранение может завершиться
ошибкой независимо от применения. Смена адреса способна прервать сеанс;
[порядок переподключения](../operations/network.md) обязателен для удалённой настройки.

## I²C

`<sel>` — имя устройства или 7-битный адрес; форма `@0xNN` явно выбирает
адрес. Это не порядковый номер строки `i2c list`. Число регистра меньше
`reg_count`, значение записи не превышает `max_value_code`.
Для текущих конфигурационных загрузчиков верхний предел последнего — 64.

| Синтаксис | Действие |
|---|---|
| `i2c list` | Перечень устройств |
| `i2c <sel> [info]` | Описание выбранного устройства |
| `i2c <sel> r <reg>` | Физическое чтение через ведущий сервис |
| `i2c <sel> w <reg> <val>` | Запись с проверкой диапазона и политики |
| `i2c <sel> addr <addr_7b>` | Меняет адрес в конфигурации и сохраняет её; это не перепрограммирование адреса внешнего чипа |
| `i2c <sel> policy` | Показывает режим |
| `i2c <sel> policy show [rules\|whitelist\|blacklist]` | Показывает правила |
| `i2c <sel> policy set <whitelist\|blacklist>` | Меняет активный режим |
| `i2c <sel> policy whitelist add <reg> <val>` | Добавляет разрешённую пару |
| `i2c <sel> policy whitelist del <reg> <val>` | Удаляет разрешённую пару |
| `i2c <sel> policy whitelist clear` | Очищает белый список |
| `i2c <sel> policy blacklist add <reg> <val>` | Добавляет запрещённую пару |
| `i2c <sel> policy blacklist del <reg> <val>` | Удаляет запрещённую пару |
| `i2c <sel> policy blacklist clear` | Очищает чёрный список |

Вертикальная черта в таблице означает выбор одного слова. Форма
`policy whitelist` или `policy blacklist` без `set` показывает список,
а не меняет режим. Пустой белый список запрещает запись, пустой чёрный
список разрешает её в пределах диапазона. Ошибки записи различают отказ
политики и отказ аппаратной операции; результат сохранения проверяют
по предупреждению и чтению JSON.

В Нейтрино команда работает через `/dev/bvstk-i2c`. Проверять отсутствие
устройства следует по журналу `bvstkd`, а не повторным запуском драйвера.

## SMI

Ниже описаны сохранённые команды FreeRTOS. В текущем аппаратном профиле
SMI выключен; это справка реализации для её последующего подключения,
а не обещание работоспособности перечисленных операций сейчас.

| Синтаксис | Действие |
|---|---|
| `smi list`, `smi <sel> info` | Перечень PHY и параметры; выбор по имени, адресу или `@адрес` |
| `smi <sel> r <reg>`, `smi <sel> w <reg> <data>` | Чтение/запись регистра |
| `smi r <phy> <reg>`, `smi w <phy> <reg> <data>` | Сохранённые прямые формы выбора PHY |
| `smi <sel> phy <phy_addr>` | Изменение адреса в модели |
| `smi <sel> policy <whitelist\|blacklist>` | Выбор режима записи |
| `smi <sel> rules` | Просмотр правил |
| `smi <sel> allow <reg>`, `deny <reg>`, `clear <reg>` | Изменение правила регистра |
| `smi <sel> autopoll` | Просмотр параметров опроса |
| `smi <sel> autopoll on`, `off` | Изменение признака опроса |
| `smi <sel> autopoll reg_delay <ms>` | Задержка между регистрами |
| `smi <sel> autopoll cycle_delay <ms>` | Задержка цикла |
| `smi <sel> autopoll regs <r0> [r1 ...]` | Набор регистров |
| `smi <sel> settings`, `smi <sel> settings clear` | Просмотр/очистка сохранённых значений |
| `smi <sel> save` | Явное сохранение модели |

В сокращённых строках полный префикс `smi <sel>` повторяется перед каждой
командой; `off` относится к `autopoll`. PHY и регистр — `0..31`,
данные — `0..65535`; регистр дополнительно ограничен конфигурацией.
Политика относится к номеру регистра. Изменение `autopoll` не создаёт
отсутствующий планировщик вызовов сервиса.

## SPI

Обычный SPI выключен в текущем профиле. Сохранённый интерфейс FreeRTOS:

| Синтаксис | Параметры |
|---|---|
| `spi info` | Текущая конфигурация |
| `spi cfg mode <single\|multi\|fallthrough>` | Режим пакетов |
| `spi cfg timeout <ticks>` | Аппаратный параметр ожидания, не миллисекунды ОС |
| `spi cfg div <even>` | Чётный делитель `2..65535`, наибольшее допустимое чётное — 65534 |
| `spi cfg read <on\|off>` | Чтение ответа из BRAM |
| `spi xfer <w0> [w1 ...]` | До 64 слов по 32 бита |

Настройки SPI не имеют собственного сохраняемого JSON. Эти команды не
описывают DCP2 SPI transfer: обычная операция передачи через DCP2 в
текущем сервере не предоставляется.

## PL SD

Служба FreeRTOS использует внешнюю SDHC/SDXC через PL SPI и DMA:

В обычной сборке используйте `sd-pl info` и файловые команды с путями
`sd-pl:/`. Карта монтируется автоматически. Следующие сырые диагностические
команды (кроме `info`) сохраняются для режима без файловой системы и
**блокируются в штатной сборке**, включая случай неудачного монтирования.

```text
sd-pl init [timeout_ms]
sd-pl info
sd-pl status
sd-pl blocklen
sd-pl read <lba>
sd-pl write <lba> <seed>
sd-pl test <lba> [count] [seed]
```

`init`: 1..120000 мс, умолчание 20000; `info`: кэшированное состояние;
`status`: CMD13; `blocklen`: диагностическая CMD16(512). `read` возвращает
512 байт только после проверки CRC16. **`write` и `test` перезаписывают
сектора без восстановления** и проверяют результат чтением. `write`
использует шаблон от seed и LBA; `test` записывает 1..8 секторов (умолчание 2),
затем проверяет весь диапазон. Числа — десятичные или `0xHEX`.

Физическая ёмкость не определяется: LBA должен существовать. В сыром режиме
ошибка I/O требует повторной явной `init`; в файловом — перезапуска системы.
Записи автоматически не повторяются. Текущий
профиль переинициализирует карту перед каждой следующей командой для
совместимости с неизменённым ядром; файловый слой использует тот же путь.
Запуск, ограничения и результаты — в
[инструкции PL SD](../operations/sd-pl-prototype.md), API — в
[главе SD](../development/drivers/sd.md).

## Тестовые потоки

Только FreeRTOS. Вместо `<bus>` выберите `i2c`, `smi`, `spi` или `uart`.

```text
<bus> stream fake enable [period_ms] [pattern] [words]
<bus> stream fake status
<bus> stream fake disable
```

`period_ms` — `10..60000` мс, умолчание 100; `words` — `1..64`,
умолчание 4; `pattern` — `counter` (умолчание), `ramp` или `toggle`.
Источник не обращается к MMIO, выключен после запуска и не сохраняется.
Подписчик DCP2 запускается [отдельной командой](../operations/dcp2.md).
Форма `stream enable` для реального источника пока сообщает недоступность.

## Память и перезапуск

Только FreeRTOS:

| Синтаксис | Действие |
|---|---|
| `mem r <addr>` | Выровненный адрес читается как 32 бита, иначе как 8 бит |
| `mem w <addr> <value>` | 32-битная запись по выровненному адресу; иначе значение должно помещаться в байт |
| `reboot -y [delay_ms]` | Перезапуск с подтверждением |
| `reboot confirm [delay_ms]` | Альтернативное подтверждение |

Доступ к памяти обходит сервисные правила. Не применяйте его к произвольному
адресу: возможны аппаратное исключение, зависание и изменение состояния.
Перезапуск прерывает сеансы и файловые операции. Подробности конкретных
проверок адреса нельзя переносить между MEM-консолью, HTTP и DCP2.

## Утилита Нейтрино bvstkctl

| Синтаксис | Действие |
|---|---|
| `bvstkctl version` | Версия программы и платформы |
| `bvstkctl pl list` | Программная таблица регионов, не обнаружение IP |
| `bvstkctl pl probe` | Диагностический доступ к регионам; не безопасная проверка всех выключенных узлов |
| `bvstkctl pl read <region> <offset> [word-count]` | Чтение слов региона |
| `bvstkctl pl write <region> <offset> <value>` | Прямая запись слова |
| `bvstkctl i2c ...` | Совместимый клиент менеджера I²C |

Смещение задаётся в байтах, для слов требуется выравнивание на 4 и
попадание в регион. Диагностические операции PL не синхронизируют
изменения с кэшем и политикой `bvstkd`. Не выполняйте их одновременно
с обслуживанием того же IP. [Карта платы](board.md) различает активные
узлы и сохранённые константы.
