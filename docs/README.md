# Документация BVSTK

BVSTK управляет и диагностирует периферию платформы Zynq-7000. Проект
имеет два альтернативных варианта исполнения: приложение FreeRTOS и
программы Нейтрино. Начните с [возможностей сборок](reference/profiles.md):
набор служб и поддержка оборудования у них различаются.
