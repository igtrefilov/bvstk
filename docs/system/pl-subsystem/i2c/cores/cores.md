# Аппаратные ядра I²C

В подсистеме два ядра. **Slave** начинает работу по START внешнего
ведущего: распознаёт адрес, принимает запись или запрашивает ответ
у PS. **Master** запускается командой программы и выполняет заранее
заданное число передач на стороне физического устройства.

Оба ядра содержат автомат линий SDA и SCL и контроллеры данных.
Автомат передаёт байт вместе с признаками фазы в виде `packet_view_t`.
Контроллеры связывают эти пакеты с FIFO и 32-битными словами BRAM.
Программа благодаря этому обслуживает фрагменты обмена, а смысл
байтов определяет [сервис](../services/services.md).

Роли master и slave относятся к внешней шине I²C. Для доступа к BRAM
каждое ядро имеет собственный ведущий порт AXI. Области запроса,
ответа и результата разделены; назначение этих областей показано
в [описании драйверов](../drivers/drivers.md#три-области-обмена).

Аппаратный разбор начинается с [ведомого ядра](slave.md), которое
получает внешний запрос. [Ведущее ядро](master.md) показывает исполнение
команды PS и получение нового значения устройства. Связь между
двумя обменами уже разобрана в [сценарии I²C](../i2c.md).
