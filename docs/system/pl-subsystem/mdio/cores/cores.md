# Аппаратные ядра MDIO

Начнём с [приёма внешнего кадра](slave.md#приём-записи): PHY 1,
REG 4, DATA `0x0120`. Slave сохраняет его в адресованную ячейку BRAM.
Затем [драйвер](../drivers/slave.md#получение-внешней-записи) заберёт
значение, а сервис определит дальнейшую операцию.

`SMI_master_0` потребуется после разрешения политики. Оно передаст
запись физическому PHY и выполнит последующее чтение регистра 4.
У двух ядер свои участки шины; пересылка кадров между ними
проходит через решение программы.

Ведомое ядро получает адрес из внешнего кадра. Ведущее получает
упакованную команду из TX FIFO. Оба используют пару PHY и REG
для вычисления адреса памяти. Поэтому данные одного регистра
сохраняют свой адрес при переходе от шины к BRAM.

Роли master и slave относятся к MDIO. Для доступа к BRAM оба ядра
имеют собственные ведущие порты AXI; регистры управления доступны
PS через ведомые порты AXI. Это разные интерфейсы одного ядра.

Начать разбор можно с [ведомого ядра](slave.md): оно показывает,
почему ответ нужно подготовить заранее. [Ведущее ядро](master.md)
раскрывает получение нового значения PHY. Затем
[драйвер](../drivers/drivers.md) связывает аппаратные события
с операциями программы.
