# Устройство системы

BVSTK — программно-аппаратная система управления и диагностики для
Zynq-7000. Процессорная часть PS исполняет программы, обслуживает Ethernet,
QSPI и SD; программируемая логика PL выполняет операции с внешними шинами.
В репозитории находятся приложения, переносимые драйверы и сервисы,
адаптеры ОС, конфигурации и средства сборки. RTL разрабатывается отдельно.

Система имеет два альтернативных варианта исполнения. FreeRTOS собирается
в одно приложение с сетевыми службами и файловым слоем. В Нейтрино
управление I²C, командные клиенты и доступ к носителям распределены между
процессами. Это не собственная универсальная ОС и не совместная загрузка
двух ОС на разных ядрах. Общие исходники позволяют повторно использовать
логику, но не делают возможности двух сборок одинаковыми.

В текущем профиле AX7020 включены I²C и инициализация SD через PL. Реализации
SMI и SPI сохранены в дереве исходников, однако соответствующие сервисы
не включены в аппаратном профиле. Различия перечислены в
[таблице возможностей](../reference/profiles.md).

## Граница системы

Программный контракт платы задаёт адреса регистров и BRAM, номера IRQ и
признаки включённых узлов. Он должен соответствовать загруженному bitstream.
Успешная сборка программы сама по себе не подтверждает это соответствие.
Точные значения и ограничения находятся в [справочнике AX7020](../reference/board.md).

Сетевые интерфейсы предназначены для доверенной инженерной сети. TCP-консоль,
HTTP и DCP2 не образуют границу безопасности: они позволяют изменять
конфигурацию и оборудование. Включение SSH не защищает остальные открытые
службы. Не подключайте такую сборку непосредственно к недоверенной сети.

Документация описывает состояние исходников и штатных сценариев сборки.
Результаты проверки на конкретной плате должны сопровождаться версиями
программы и аппаратного экспорта; порядок записи этих сведений приведён в
[главе о проверках](../development/testing.md).
