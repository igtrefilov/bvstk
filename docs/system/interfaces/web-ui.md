# Веб-интерфейс

Браузер получает статику из `flash:/www` и обращается к HTTP API.
Он показывает состояние сервисов, помогает подготовить запрос
и отображает результат. Решение о допустимости аппаратной операции
остаётся в PS, поскольку открытых клиентов может быть несколько.

Редактор хранит локальный черновик. Обновление текущего состояния
не должно молча стирать несохранённые правки пользователя.
При применении сервер сверяет ревизию; после конфликта нужен свежий
снимок. Применённая конфигурация и сохранённый профиль отображаются
как отдельные состояния.

Вкладки регистров и показателей читают кэш. Карта регистров переводит
числа в подписи и битовые поля, а `view.js` задаёт индивидуальную форму
в изолированном iframe. Источник `settings`, недостоверная запись
или отсутствующий регистр не превращаются в показание устройства.
Составная величина может объединять регистры, прочитанные в разные моменты.

Вкладки наблюдений читают журнал с курсором. Пауза останавливает
получение строк браузером, но события на плате продолжают записываться.
При возврате интерфейс дочитывает доступную историю и показывает
пропуски. Эти различия раскрыты в [главе о кэше и журналах](../observation/observation.md).

Действия пользователя, установка фронтенда и восстановление связи
описаны в [практической главе](../../operations/web-ui.md).
