# Консоль

Во FreeRTOS UART, TCP-консоль и включённый SSH передают строки
в общий shell. Он хранит состояние сеанса, разбирает команду
и выбирает обработчик. Аппаратная операция выполняется через
экземпляр сервиса из рабочей среды.

Текстовый сеанс удобен для ручной работы, но его вывод не является
двоичным контрактом внешней автоматизации. Имя устройства предпочтительнее
числового ID: список профилей упорядочивается при старте, и добавление
нового профиля может изменить номера существующих устройств.

В Нейтрино пользователь работает в оболочке ОС. Программы BVSTK
передают запросы в `bvstkd` через предусмотренные интерфейсы;
консоль FreeRTOS на TCP-порту `8888` там не запускается.

Практика подключения описана в [работе с консолью](../../operations/console.md),
точный синтаксис — в [справочнике команд](../../reference/console-commands.md).
