# BVSTK

BVSTK связывает внешнего ведущего с ведомым устройством через ядра PL
и программу PS. Программа хранит значения, проверяет правила записи
и предоставляет доступ к состоянию через консоль и сетевые интерфейсы.

## Устройство системы

Начните с [принятой модели и уровней L0–L4](system/system.md), затем
перейдите к [архитектурным картам](system/architecture/architecture.md).
Далее статья последовательно разбирает запуск, конфигурацию,
транзакции I²C, MDIO и SD, файлы и внешние интерфейсы.

На каждом шаге рассматривается, где находятся данные, кто ими владеет
и какое событие позволяет передать их следующему участнику. Условные
обозначения вводятся перед первой архитектурной картой.
