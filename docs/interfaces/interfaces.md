# Протоколы и API

BVSTK предоставляет несколько интерфейсов управления и диагностики. Они
передают операции одним и тем же сервисам платформы, но используют разные
форматы сообщений и рассчитаны на разные сценарии работы.

## Интерфейсы

- [Протокол DCP2](dcp2/01-intro.md) — двоичный обмен с устройством по TCP;
  для автоматизации также доступен [готовый клиент](dcp2/client.md).
- [Интерфейс HTTP API](http/http.md) — запросы к состоянию системы,
  настройкам устройств, журналам и файлам.
- [Консоль](console.md) — текстовые команды через UART, TCP или SSH.

Архитектурные границы обработчиков и общих сервисов описаны в разделе
[устройства BVSTK](../system/system.md).
