# Статусы DCP2 и наблюдаемых операций

## Статус ответа

`status:u16` начинает тело ответа; старший байт передаётся первым.
Ненулевой статус не гарантирует откат уже выполненных действий.

| Код      | Имя                        | Значение                                   |
| -------- | -------------------------- | ------------------------------------------ |
| `0x0000` | `OK`                       | Успех                                      |
| `0x0001` | `ERR_MALFORMED`            | Неверный формат параметров                 |
| `0x0002` | `ERR_UNSUPPORTED`          | Операция или возможность не поддерживается |
| `0x0003` | `ERR_DENIED`               | Отказ по политике доступа                  |
| `0x0004` | `ERR_BUSY`                 | Нужный ресурс занят или пока недоступен    |
| `0x0005` | `ERR_TIMEOUT`              | Обработчик не дождался завершения          |
| `0x0006` | `ERR_RANGE`                | Параметр вне допустимого диапазона         |
| `0x0007` | `ERR_INTERNAL`             | Внутренняя ошибка                          |
| `0x0100` | `ERR_FS_NOT_FOUND`         | Файловый объект или том не найден          |
| `0x0101` | `ERR_FS_NOT_READY`         | Том не готов                               |
| `0x0102` | `ERR_FS_BAD_HANDLE`        | Файловый дескриптор недействителен         |
| `0x0103` | `ERR_FS_TYPE`              | Неверный тип файлового объекта             |
| `0x0104` | `ERR_FS_IO`                | Ошибка файлового ввода-вывода              |
| `0x0105` | `ERR_FS_CHANGED`           | Изменился читаемый файл                    |
| `0x0200` | `ERR_CACHE_NOT_FOUND`      | Устройство или подписка кэша не найдены    |
| `0x0201` | `ERR_CACHE_STALE_SNAPSHOT` | Снимок кэша истёк или заменён              |

Условия: [политики](policies.md#ошибки), [FS](fs.md#ошибки-чтения-и-восстановление),
[CACHE](cache.md#ограничения-и-ошибки).

## Статус в NOTIFY и BVT1

Результат наблюдаемого действия. Значения из
[bvstk_status.h](../../../../src/shared/base/bvstk_status.h); не являются статусами ответа DCP2.

| Код | Имя статуса | Значение |
|---:|---|---|
| 0 | `BVSTK_OK` | Успех |
| 1 | `BVSTK_ERR_MALFORMED` | Неверный формат |
| 2 | `BVSTK_ERR_UNSUPPORTED` | Возможность не поддерживается |
| 3 | `BVSTK_ERR_DENIED` | Отказ доступа |
| 4 | `BVSTK_ERR_BUSY` | Ресурс занят |
| 5 | `BVSTK_ERR_TIMEOUT` | Истекло ожидание |
| 6 | `BVSTK_ERR_RANGE` | Параметр вне диапазона |
| 7 | `BVSTK_ERR_NOT_READY` | Сервис не готов |
| 8 | `BVSTK_ERR_NOT_FOUND` | Объект не найден |
| 9 | `BVSTK_ERR_IO` | Ошибка ввода-вывода |
| 10 | `BVSTK_ERR_INTERNAL` | Внутренняя ошибка |
