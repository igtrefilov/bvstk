# Форматы CACHE

| Параметр | Значение |
|---|---|
| Сервис | `srv=0x08` |
| Сервер | FreeRTOS и `bvstkd` Нейтрино (общая сессия DCP2) |
| Адаптеры | Программные кэши I²C и MDIO |
| Физический обмен и изменение политики | Запросами CACHE не запускаются |

## Команды

Устройство с несколькими I²C-пространствами представляет собой одну цель
CACHE. Все его ресурсы имеют уникальные ID из профиля. Пара `space`, `address`
разрешается клиентом по профилю; в кадр CACHE дополнительные адресные поля
не добавляются. Снимок и подписка охватывают ресурсы всех пространств.

| `opcode` | Команда |
|---|---|
| `0x20` | CACHE_GET |
| `0x21` | CACHE_SUBSCRIBE |
| `0x22` | CACHE_UNSUBSCRIBE |

## Форматы запросов

Поля `body` перечислены в порядке передачи. Общий [кадр](frame.md)
имеет `ver=2`; тело CACHE — `cache_version=1`.

| Команда | Поля запроса | Данные успешного ответа после `status:u16` |
|---|---|---|
| GET | `cache_version:u8`, `subsystem:string`, `device:string`, `snapshot_id:u32`, `first:u16` | Страница снимка |
| SUBSCRIBE | `cache_version:u8`, `subsystem:string`, `device:string` | Первая страница снимка |
| UNSUBSCRIBE | `cache_version:u8`, `subscription_id:u16` | Отсутствуют |

| Поле или условие | Требование |
|---|---|
| `string` | `length:u8`, затем `length` ASCII-байт без NUL |
| Имя | 1–31 символ: латинские буквы, цифры, `_`, `-`, `.`; регистр значим |
| Порядок байтов чисел | Старший байт первым |
| Новый GET | `snapshot_id=0`, `first=0` |
| Продолжение GET | Тот же `snapshot_id` и имена цели; `first=next` предыдущей страницы |
| Ошибочный ответ | Только ненулевой статус |

## Страница снимка

Поля после общего статуса, в порядке передачи:

| Поле | Тип | Содержание |
|---|---|---|
| `cache_version` | `u8` | 1 |
| `kind` | `u8` | 0, снимок |
| `subscription_id` | `u16` | 0 для самостоятельного GET |
| `snapshot_id` | `u32` | Ненулевой токен снимка |
| `generation` | `u32` | Поколение ресурсов |
| `revision` | `u64` | Ревизия снимка |
| `captured_ms` | `u64` | Время фиксации, мс работы системы |
| `total` | `u16` | Число ресурсов во всём снимке |
| `first` | `u16` | Индекс первой записи страницы |
| `count` | `u16` | Число записей страницы |
| `next` | `u16` | Индекс следующей страницы; `0xFFFF` — конец |
| `presence` | `u8` | 0 unknown, 1 ready, 2 unavailable |
| `resources` | Массив | `count` целых записей ресурсов |

| Ограничение | Значение |
|---|---|
| Полезная нагрузка | `6 + 37 + размер записей <= 4096` |
| Запись ресурса | Не разбивается между страницами |
| Число записей страницы | Переменное; задаётся `count` |
| Повтор страницы сохранённого снимка | Те же данные |
| Пустой кэш | Успех, `total=0` |

### Запись ресурса

| Поле | Тип | Содержание |
|---|---|---|
| `resource_id` | `string` | ID из профиля |
| `width_bits` | `u8` | Разрядность от 1 до 64 |
| `valid` | `u8` | 0 или 1 |
| `source` | `u8` | 0 unknown, 1 settings, 2 device |
| `value` | `u64` | Беззнаковое значение |
| `updated_ms` | `u64` | Время получения значения |

| Свойство | Значение |
|---|---|
| Размер записи | `20 + длина ID` байт |
| `value` | Всегда `u64`, независимо от `width_bits` |
| Начальная пустая запись | `valid=0`, `source=unknown`, `value=0`, `updated_ms=0` |
| Нулевое достоверное значение | `valid=1`, `value=0` |
| `source=settings` | Начальное значение из профиля |
| `source=device` | Значение от устройства |
| Согласованность снимка | По памяти PS; регистры могли быть прочитаны в разное время |
| Готовность устройства | Отдельное поле `presence` |

## Формат изменения

`srv=0x08`, `op=0x61`, `seq=0`. Поля `body` в порядке передачи;
общего статуса ответа нет.

| Поле | Тип | Содержание |
|---|---|---|
| `cache_version` | `u8` | 1 |
| `kind` | `u8` | 1 ресурс, 2 готовность, 3 `RESYNC_REQUIRED` |
| `subscription_id` | `u16` | Подписка, к которой относится изменение |
| `generation` | `u32` | Поколение ресурсов |
| `revision` | `u64` | Ревизия |
| `time_ms` | `u64` | Время изменения или уведомления о потере |
| `presence` | `u8` | Готовность устройства |
| `reason` | `u8` | Для обычного изменения 0 |
| `count` | `u16` | 1 для ресурса, иначе 0 |
| `resources` | Массив | При `kind=1` одна [запись ресурса](#запись-ресурса) |

| `reason` | Причина RESYNC_REQUIRED |
|---:|---|
| 1 | Переполнение журнала |
| 2 | Смена поколения |
| 3 | Истечение срока начального снимка |

| Поле при RESYNC_REQUIRED | Значение |
|---|---|
| `generation`, `revision` | Последнее согласованное состояние подписки |
| `presence` | Игнорируется |
| `count` | 0; массива ресурсов нет |

## Ограничения и ошибки

| Ресурс | Текущий предел |
|---|---:|
| Устройства в реестре | 48 |
| Ресурсы одного устройства | 256 |
| Записи общего журнала | 512 |
| Подписки на соединение | 8 |
| Сохранённые снимки на соединение | 1 |
| Неактивность снимка до истечения | 30 секунд |

| Ограничение | Правило |
|---|---|
| Новый снимок | Заменяет прежний токен |
| Незавершённый начальный снимок подписки | Другой снимок не начинается: `ERR_BUSY`; отмена через UNSUBSCRIBE |
| Успешное чтение страницы | Продлевает срок снимка |
| Истечение дочитанного снимка | Не останавливает активную подписку |
| Журнал | Общий для устройств; записи вытесняются и изменениями других устройств |
| TCP в текущем сервере FreeRTOS | Одновременно обслуживается одно соединение |

| Код | Значение |
|---|---|
| `ERR_MALFORMED` | Неверное тело запроса |
| `ERR_UNSUPPORTED` | Операция или версия не поддерживается |
| `ERR_BUSY` | Заняты подписки или не завершён снимок |
| `ERR_RANGE` | Неверный индекс страницы |
| `ERR_CACHE_NOT_FOUND` | Устройство или ID подписки не найдены |
| `ERR_CACHE_STALE_SNAPSHOT` | Токен истёк, заменён или принадлежит другой цели |

## Последовательность страниц и изменений

| Условие | Правило |
|---|---|
| Порядок страниц | С индекса 0; каждый следующий `first=next` |
| Начальный снимок подписки | Одно поколение и ревизия R; события удерживаются до последовательной выдачи всех страниц |
| Обычное событие после снимка | Та же подписка и поколение; ревизия R+1, затем R+2 и далее |
| Пропуск ревизии или RESYNC_REQUIRED | Требуется новый SUBSCRIBE |
| Повтор SUBSCRIBE той же цели | Заменяет её подписку новым снимком и позицией журнала |
| Закрытие TCP | Все идентификаторы соединения недействительны |
| Публикация значения, смена готовности, потеря достоверности | Увеличивают ревизию |
| Повторное успешное чтение того же значения | Увеличивает ревизию |
| Повторная очистка пустого ресурса | Не увеличивает ревизию |
| Отсутствие нового события | Само по себе не означает потерю согласованности |
