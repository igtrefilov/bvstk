# Форматы файлового сервиса

| Параметр | Значение |
|---|---|
| Сервис | `srv=0x07` |
| Версия FS | 1 |
| Сервер | FreeRTOS; в текущем `bvstkd` не подключён |
| Тома | `sd`, `flash`, `sd-pl`; требуется готовый том |
| Операции | Чтение FILE, TREE, TAR |
| Запись, удаление, форматирование, события FS | Не предусмотрены |

## Пути и готовность томов

| Параметр | Ограничение |
|---|---|
| Форма пути | Абсолютный путь `volume:/path` |
| `path_len` | Число байтов UTF-8; NUL не передаётся |
| Имя тома | 1–15 строчных ASCII-букв, цифр или дефисов; числовые обозначения FatFs не используются |
| Конечный `/` каталога | Нормализуется |
| Компоненты | `.` и `..`, пустые промежуточные компоненты запрещены |
| Запрещённые символы | U+0000–U+001F, U+007F, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `\|` |
| Неверный UTF-8 или превышение длины | Запрос отклоняется; усечения нет |
| Имя не представимо в кодировке носителя | `ERR_RANGE` |
| Монтирование и форматирование | Запросами FS не запускаются |
| Имя тома в FS_INFO | Не подтверждает его готовность; состояние передаётся отдельно |

## Виды потока

| `kind` | Представление |
|---:|---|
| 1 | FILE: последовательные байты файла, без произвольного смещения |
| 2 | TREE: записи файлов и каталогов |
| 3 | TAR: рекурсивный несжатый архив |

| TREE | Правило |
|---|---|
| Без RECURSIVE | Непосредственные дети каталога |
| С RECURSIVE | Обход в глубину; каталог перед потомками |
| Порядок соседей | Определяется файловой системой |
| Корень | Не включается |
| Пустые каталоги | Включаются |

### Запись TREE

Поля FS_TREE_ENTRY в порядке передачи:

| Поле | Тип | Значение |
|---|---|---|
| `entry_len` | `u16` | Полная длина записи: `14 + path_len` |
| `type` | `u8` | 1 — файл, 2 — каталог |
| `reserved` | `u8` | Ноль |
| `size` | `u64` | Размер файла; для каталога ноль |
| `path_len` | `u16` | Длина относительного пути в байтах UTF-8 |
| `path` | `path_len` байт | Путь относительно корня обхода |

| Условие | Требование |
|---|---|
| Граница записи | Определяется `entry_len`; может пересекать блоки FS |
| EOF внутри записи | Ошибка потока |

### Формат TAR

| Свойство | Значение |
|---|---|
| Формат | Несжатый ustar; локальные PAX-заголовки `path` и `size` для длинных, не-ASCII имён и больших размеров |
| Обход | Всегда рекурсивный |
| Пути | Относительные |
| Пустые каталоги | Включаются |
| UID, GID, mtime | 0 |
| Режим файла | `0644` |
| Режим каталога | `0755` |
| Конец архива | Два нулевых блока по 512 байт |
| Границы блоков FS | Не обязаны совпадать с блоками TAR |

## Форматы команд

Поля таблиц расположены в порядке передачи. Данные ответа следуют
за общим `status:u16`; при ошибке дополнительных данных нет.

| `opcode` | Команда |
|---|---|
| `0x00` | FS_INFO |
| `0x01` | FS_STAT |
| `0x02` | FS_OPEN |
| `0x03` | FS_READ |
| `0x04` | FS_CLOSE |

### FS_INFO: возможности сервиса

Запрос: пустое тело. Данные ответа:

| Поле | Тип | Содержание |
|---|---|---|
| `fs_version` | `u16` | Версия FS, сейчас 1 |
| `capabilities` | `u32` | Поддерживаемые возможности |
| `max_block_size` | `u16` | Максимум `data_len`, сейчас 3072 |
| `max_path_bytes` | `u16` | Предел абсолютного пути, сейчас 511 |
| `max_depth` | `u16` | Глубина стека каталогов с учётом корня, сейчас 16 |
| `max_handles` | `u16` | Число потоков на соединение, сейчас 2 |
| `idle_timeout_ms` | `u32` | Таймаут неактивного потока, сейчас 30000 мс |
| `volume_count` | `u16` | Число следующих записей томов |
| `volume[]` | Переменный массив | Записи `FS_VOLUME` |

Запись FS_VOLUME:

| Поле | Тип | Значение |
|---|---|---|
| `state` | `u8` | 0 — неготовый, 1 — готовый, 2 — не поддержан сборкой |
| `name_len` | `u8` | Длина имени |
| `name` | `name_len` байт | Без NUL и без `:/` |

| Бит `capabilities` | Возможность |
|---:|---|
| 0 | FILE |
| 1 | TREE |
| 2 | TREE_RECURSIVE |
| 3 | TAR |
| 4 | UTF8_PATHS |
| 5 | LIVE_READ: чтение текущей файловой системы без атомарного снимка |

Текущая маска `0x3F`. Неизвестные биты игнорируются.

### FS_STAT: сведения об объекте

| Поле запроса | Тип | Значение |
|---|---|---|
| `path_len` | `u16` | Длина пути |
| `path` | `path_len` байт | Абсолютный путь |

| Поле ответа | Тип | Значение |
|---|---|---|
| `type` | `u8` | 1 — файл, 2 — каталог |
| `attributes` | `u8` | Биты 0–3: readonly, hidden, system, archive; остальные нулевые |
| `size` | `u64` | Размер файла; для каталога 0 |

Время изменения в FS v1 не передаётся.

### FS_OPEN: создание потока

| Поле запроса | Тип | Значение |
|---|---|---|
| `open_id` | `u32` | Ненулевой номер попытки открытия |
| `kind` | `u8` | FILE, TREE или TAR |
| `flags` | `u8` | Бит 0 — `RECURSIVE` для TREE |
| `requested_block_size` | `u16` | 0 — максимум сервера, иначе размер от 1 до максимума |
| `path_len` | `u16` | Длина пути |
| `path` | `path_len` байт | Файл для FILE, каталог для TREE или TAR |

Для FILE и TAR флаги нулевые; для TREE допустим только бит 0.

| Поле ответа | Тип | Значение |
|---|---|---|
| `handle` | `u32` | Дескриптор потока |
| `block_size` | `u16` | Согласованный предел размера блока |
| `total_size` | `u64` | Размер FILE; для TREE и TAR `0xFFFFFFFFFFFFFFFF` |

### FS_READ: очередной блок

| Поле запроса | Тип | Значение |
|---|---|---|
| `handle` | `u32` | Дескриптор OPEN |
| `block_no` | `u32` | Номер блока, начиная с 0 |

| Поле ответа | Тип | Значение |
|---|---|---|
| `handle` | `u32` | Дескриптор из запроса |
| `block_no` | `u32` | Номер из запроса |
| `flags` | `u8` | Бит 0 — EOF, остальные нулевые |
| `reserved` | `u8` | Ноль |
| `data_len` | `u16` | Число байтов данных, не больше `block_size` |
| `data` | `data_len` байт | Фрагмент потока |

| Условие | Требование |
|---|---|
| Формат `data` | Определяется `kind` из OPEN |
| Пустой FILE или TREE | Блок 0, `data_len=0`, EOF |
| Пустой успешный блок без EOF | Недопустим |
| Последний блок | Может содержать данные; повторяется до закрытия или таймаута |
| Полнота FILE после EOF | Сумма `data_len` равна `total_size` |

### FS_CLOSE: освобождение потока

| Параметр | Значение |
|---|---|
| Запрос | `handle:u32` |
| Успешный ответ | Только общий статус |
| `handle=0` | `ERR_FS_BAD_HANDLE` |
| Отсутствующий ненулевой `handle` | Успех; повтор CLOSE допустим |

## Ошибки чтения и восстановление

| Условие | Результат или требование |
|---|---|
| Неактивность 30 секунд или закрытие TCP | Поток освобождается |
| Запрос к прежнему дескриптору | `ERR_FS_BAD_HANDLE` |
| Повторное открытие | Новый поток начинается с блока 0 |
| Ошибка формирования блока | Терминальная для дескриптора; последующие READ возвращают ту же ошибку |
| Обнаружены смена размера, отметки изменения, удаление или досрочный конец файла | `ERR_FS_CHANGED` |
| Изменение содержимого при прежнем размере и отметке | Может остаться незамеченным |
| Параллельное изменение дерева | Согласованный снимок не гарантируется |
| Таймаут приёма | Частичный кадр сохраняется; поздние ответы отделяются по `seq` |
| Ошибка с возможной частичной отправкой запроса | Требуется новое соединение |

Коды: [статусы ответа](statuses.md#статус-ответа).

### Повтор OPEN и READ

| Операция | Условие | Результат |
|---|---|---|
| Повтор OPEN | Прежние ненулевой `open_id` и параметры; поток существует | Тот же дескриптор |
| Повтор OPEN | Прежний `open_id`, другие параметры | `ERR_MALFORMED` |
| READ | Очередной номер блока | Продвижение потока |
| Повтор READ | Последний успешно выданный блок | Те же данные без продвижения |
| READ | Пропуск номера или более старый блок | `ERR_RANGE` |
| Повторная отправка | Новый `seq`; идентификаторы FS сохранены | Отдельный запрос DCP2 |
| Повторное использование `handle` | В том же соединении | Не допускается сервером |
