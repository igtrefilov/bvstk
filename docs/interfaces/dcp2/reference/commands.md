# Сервисы и основные команды DCP2

Типы чисел и порядок байтов: [формат кадра](frame.md).
Поля запросов указаны в порядке передачи; данные ответа следуют за `status:u16`.

## Сервисы

| `srv` | Сервис | Операции |
|---|---|---|
| `0x00` | PING | Проверка ответа сервера |
| `0x01` | MEM | Доступ к разрешённым областям памяти и регистрам PL |
| `0x02` | I2C | Регистры I²C, политика записи, потоковая подписка |
| `0x03` | MDIO | Регистры PHY, политика записи, потоковая подписка |
| `0x04` | SPI | Потоковая подписка |
| `0x05` | UART | Потоковая подписка |
| `0x06` | NOTIFY | [Уведомления](events.md) |
| `0x07` | FS | [Чтение файлов и каталогов](fs.md) |
| `0x08` | CACHE | [Снимки кэша и изменения](cache.md) |
| `0x09` | POLICY | [Управление политиками по ID профиля](policies.md#адресация-по-id-профиля) |

| Возможность | Сервер FreeRTOS | Текущий `bvstkd` |
|---|---|---|
| PING, MEM | Подключены | Подключены |
| I²C | При наличии PL и готового сервиса | Подключён |
| MDIO | При наличии PL и готового сервиса | Общий обработчик есть; сервис не подключён |
| POLICY по ID профиля | I²C и MDIO | I²C |
| Обычные операции SPI, UART | `ERR_UNSUPPORTED` | Не подключены |
| NOTIFY, STREAM, FS, CACHE | Подключены | Не обслуживаются |

Потоковая подписка не подтверждает аппаратный обмен; источник может быть тестовым.

## Коды основных операций

| Сервис | `opcode` | Операция |
|---|---|---|
| PING | `0x00` | PING |
| MEM | `0x00` | MEM_READ |
| MEM | `0x01` | MEM_WRITE |
| I2C | `0x00` | READ_REG |

| Запрос | Данные успешного ответа |
|---|---|
| Пустое тело | Отсутствуют |

## MEM: чтение и запись памяти

| Поле запроса | Тип | Значение |
|---|---|---|
| `flags` | `u8` | Флаги доступа; см. ограничения приложения |
| `width` | `u8` | Разрядность элемента в битах |
| `addr` | `u32` | Начальный физический адрес |
| `count` | `u16` | Число элементов |
| `data` | `count` элементов разрядности `width` | Только в MEM_WRITE |

| Ответ | Данные после статуса |
|---|---|
| MEM_READ | Массив `data` из `count` элементов разрядности `width` |
| MEM_WRITE | Отсутствуют |

| Ограничение | FreeRTOS | `bvstkd` |
|---|---|---|
| `flags` | Бит 0 — `AUTOINC`; остальные нулевые | То же |
| `width` | 8, 16, 32, 64 | 8, 16, 32, 64 для BRAM; 32 для регистров управления |
| `count` | От 1, в пределах допустимого размера кадра | То же |
| Продвижение адреса | На `width / 8` при `AUTOINC=1`; без продвижения при 0 | То же |
| Выравнивание `addr` | По размеру элемента | То же |
| Разрешённые адреса | Порт разрешает прямой доступ в 32-битное адресное пространство | Только целиком внутри региона таблицы PL |

| Размер | Требование |
|---|---|
| `data_size` | `count × width / 8` |
| Ответ MEM_READ | `6 + data_size <= 4096` |
| Запрос MEM_WRITE | `4 + 8 + data_size <= 4096`; длина массива точно равна `data_size` |
| Порядок байтов элементов | Старший байт первым |

Обработчик проверяет формат, размер ответа и полный диапазон запроса
до первого аппаратного чтения или записи. Нулевое число элементов,
невыравненный адрес и выход диапазона возвращают RANGE; неизвестные
флаги — MALFORMED, неподдерживаемая разрядность — UNSUPPORTED.
64-битный элемент передаётся как старшее 32-битное слово по младшему
адресу и младшее слово по адресу `+4`; атомарность не гарантируется.

Нейтрино применяет AUTOINC по общим правилам.
Старые сценарии, передававшие `flags=0` для соседних слов, должны включить
AUTOINC. Ограничение прежнего сервера в 256 элементов снято; остаётся
общий предел размера кадра.

## Регистровые команды

У I²C-профиля с `transport.address_spaces` поле `addr7` выбирает
пространство, а `reg` задаёт локальный номер регистра. PS сопоставляет
эту пару с ресурсом профиля. Выход за размер пространства возвращает
`ERR_RANGE`; на соседнее пространство операция не переносится.

| Сервис | Команда | Поля запроса в порядке передачи | Данные успешного ответа |
|---|---|---|---|
| I2C | READ_REG | `addr7:u8`, `reg:u8` | `val:u8` |
| I2C | WRITE_REG | `addr7:u8`, `reg:u8`, `val:u8` | Отсутствуют |
| MDIO | READ | `phy:u8`, `reg:u8` | `val16:u16` |
| MDIO | WRITE | `phy:u8`, `reg:u8`, `val16:u16` | Отсутствуют |

## I²C: регистр и политика записи

| Параметр | Ограничение |
|---|---|
| `addr7` | Семибитный адрес без бита чтения; устройство зарегистрировано в сервисе |
| `reg`, `val` | В пределах профиля устройства |
| Запись | Проверяется политикой; при запрете `ERR_DENIED` до аппаратного обмена |
| Политика | [Отдельные команды](policies.md) |

## MDIO: регистры PHY

| Параметр | Ограничение |
|---|---|
| `phy`, `reg` | 0–31, Clause 22; PHY зарегистрирован в сервисе |
| `val16` | 16-битное беззнаковое значение |
| Запись | Проверяется политикой сервиса |
| Политика | [Отдельные команды](policies.md); правило содержит маску |
