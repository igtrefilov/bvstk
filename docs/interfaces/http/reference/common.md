# Общие требования HTTP API

Текущий сервер FreeRTOS. Ограничения конкретного маршрута имеют приоритет.

## Общие правила

| Свойство | Требование |
|---|---|
| Методы | GET, PUT |
| Ответ | HTTP/1.0, `Connection: close` |
| Постоянное соединение, конвейер запросов, Range | Не поддерживаются |
| Длина PUT | `Content-Length` или `Transfer-Encoding: chunked`; без обоих — 411 |
| Некорректные заголовки длины | Повтор Content-Length, неверное число, неподдерживаемое Transfer-Encoding и сочетание chunked с Content-Length отклоняются |
| JSON-ответ | `application/json`; прежние маршруты также указывают `charset=utf-8` |
| Ошибки прежних маршрутов | Обычно текстовые |
| JSON-запрос | Объект с уникальными ключами; десятичные целые, строки и логические значения по формату операции |
| Проверка JSON в прежних маршрутах | Поиск полей; полная проверка схемы не гарантирована |
| Неизвестные поля и неверные типы | Единое поведение прежних маршрутов не гарантировано |
| Ожидание заголовка | 5 секунд без входных данных |
| Приём тела и отправка ответа | 30 секунд без прогресса; не предел FAT или всего запроса |
| Одновременное выполнение | Один запрос |

| PUT-маршрут | Максимум тела, помещающийся в буфер обработчика |
|---|---:|
| `/api/net` | 1023 байта |
| `/api/i2c` | 2047 байт |
| `/api/diag/i2c/read`, `/api/diag/i2c/write` | 511 байт |
| MEM, reboot | 255 байт |

Превышение буферов прежних маршрутов может привести к частичному разбору;
ответ 413 не гарантирован. Пределы `/api/ui/` и потоковых PUT заданы отдельно.

## Правила API устройств

| Параметр | Требование |
|---|---|
| Query | URL-кодирование; числа десятичные, неотрицательные, без суффиксов |
| Недопустимые query | Повтор запрошенного ключа, неверное percent-кодирование, NUL, управляющий символ, переполнение |
| JSON | UTF-8 |
| Успех действия | HTTP 200, `ok:true`; дополнительные поля заданы маршрутом |
| Ошибка действия | Соответствующий HTTP-код, `ok:false`, строка `error` |
| Список или снимок | `ok` не обязателен |
| Ошибка каталога после начала ответа | Передаётся в теле; HTTP 200 не подтверждает успех и полноту JSON |
| Кэширование ответов | Запрещено |
| Аутентификация, TLS, атомарные транзакции между клиентами | Отсутствуют |

| HTTP-код | Условие |
|---:|---|
| 400 | Неверные данные или диапазон |
| 403 | Отказ политики |
| 404 | Неизвестный маршрут или устройство |
| 405 | Неподдерживаемый метод |
| 423 | Сервис занят |
| 503 | Сервис не готов |
| 504 | Таймаут сервиса |
| 500 | Прочая ошибка |
