# Системные маршруты HTTP

[Общие требования](common.md).

## Сведения о системе

Метод GET. Все поля соответствующего обработчика обязательны.

| Маршрут | Поле | Тип и смысл |
|---|---|---|
| `/api/version` | `build_date`, `build_time` | Строки макросов даты и времени компиляции; не идентификатор Git |
| | `http_port` | Целое, порт сервера |
| `/api/rtos` | `uptime_ms` | Целое, миллисекунды из счётчика тиков FreeRTOS |
| | `tick_rate_hz` | Целое, частота тиков в Гц |
| | `heap_free` | Целое, свободная куча в байтах |
| | `heap_min_ever` | Целое, минимальная наблюдавшаяся свободная куча в байтах |

`uptime_ms` наследует переполнение исходного счётчика тиков FreeRTOS.

## GET /api/net

| Поле | Тип | Смысл |
|---|---|---|
| `ip`, `netmask`, `gateway` | Строка | Параметры работающего интерфейса; могут быть пустыми до его создания |
| `mac` | Строка | Шесть октетов через двоеточие |
| `mode` | Строка | `static` или `dhcp` по состоянию сборки lwIP |
| `dhcp` | Логическое | Получен ли адрес DHCP, если эта возможность собрана |
| `up` | Логическое | Интерфейс административно поднят |
| `link_up` | Логическое | Состояние линии по данным lwIP |

Все поля присутствуют. Источник — работающий интерфейс, не `network.json`.
Текущий запуск использует статические параметры.

## PUT /api/net

| Поле запроса | Тип | Условие |
|---|---|---|
| `ip` | Строка | Обязательно: `a.b.c.d` или `a.b.c.d/prefix` |
| `netmask` | Строка | При IP без префикса задаёт маску; имеет приоритет над отдельным `prefix` |
| `prefix` | Целое | `0..32`, альтернатива `netmask` |
| `gateway` | Строка | Обязательный IPv4 |
| `mac` | Строка | Обязательные шесть октетов через двоеточие |
| `apply` | Логическое | Необязательно; по умолчанию `true` |

| Условие | Правило |
|---|---|
| Префикс внутри `ip` | Определяет маску; передаётся одна форма маски |
| Проверка IPv4 | По октетам; пригодность параметров для конкретной сети не проверяется |
| `apply:false` | Работающий интерфейс не изменяется |
| Порядок выполнения | Обновление модели, попытка сохранения, применение, ответ |
| Ошибка сохранения | Не отменяет применение; может не давать HTTP-ошибку |
| Смена IP | Ответ может быть потерян |

Ответ HTTP 200:

| Поле | Тип | Значение |
|---|---|---|
| `ok` | Логическое | `true` |
| `saved` | Логическое | Успех вызова сохранения |
| `applied` | Логическое | Выполнена ветвь обновления существующего `netif` |

HTTP 400: `empty body`, `missing/bad ip`, `bad ip/prefix`,
`missing netmask/prefix`, `bad netmask`, `bad prefix`,
`missing/bad gateway`, `missing/bad mac`.

## Диагностические операции MEM

| Маршрут | Обязательные поля запроса | Ответ HTTP 200 |
|---|---|---|
| `PUT /api/diag/mem/read` | `addr`: целое 0–4294967295 | `ok:true`, `width`: 32 или 8, `val`: беззнаковое значение |
| `PUT /api/diag/mem/write` | `addr`, `val`: целые 0–4294967295; `confirm:true` | `ok:true` |

| Условие | Результат |
|---|---|
| Адрес выровнен на 4 | Операция 32 бита |
| Адрес не выровнен на 4 | Операция 8 бит; для записи `val <= 255` |
| Неверные аргументы, нет подтверждения, слишком большое байтовое значение | 400 |
| Адрес вне включённых окон | 403, `address not available`; список окон отличается от DCP2 MEM |
| Политика устройства | Не проверяется |
| Значение регистра, совместимость bitstream | Не проверяются; аппаратное исключение не исключено |

## PUT /api/reboot

| Поле запроса | Требование |
|---|---|
| `confirm` | Обязательно `true` |
| `delay_ms` | Необязательное неотрицательное целое; по умолчанию 1000, максимум 5000 |

| Условие | Ответ |
|---|---|
| Запрос принят | HTTP 200, `ok:true`, `rebooting:true` |
| Пустое тело или нет подтверждения | 400 |

Задача перезапуска создаётся после ответа; результат создания в ответ не входит.
