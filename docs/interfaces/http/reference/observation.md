# Формат журналов наблюдений HTTP

[Общие требования](common.md).

## Журналы наблюдений

`GET /api/ui/observe`. PUT не поддерживается; физическое чтение не выполняется.

| Query | Значение |
|---|---|
| `bus` | `i2c` или `mdio` |
| `channel` | `telemetry` или `events` |
| `address` | Необязательный адрес: 0–127 для I²C, 0–31 для MDIO; без него — вся шина |
| `after` | Позиция после предыдущей записи; отсутствие — начало сохранённой истории, 0 — позиция перед первой записью |

| Поле ответа | Значение |
|---|---|
| `records` | До 32 записей |
| `next` | Курсор следующего запроса; десятичная строка, 64 бита |
| `head` | Текущая позиция журнала; десятичная строка, 64 бита |
| `more` | Есть следующая порция |
| `lost` | Число перезаписанных подтверждённых записей между курсором и началом доступной истории; десятичная строка |
| `capacity` | 256 |
| `reset` | Курсор за концом журнала |
| `uptime_ms` | Время работы PS; уменьшение требует нового чтения без `after` |

| Правило | Ограничение |
|---|---|
| Состав журнала | Подтверждённые наблюдения; служебные пробы неподтверждённых профилей и отсутствующих устройств исключены |
| Продвижение курсора | Включает отфильтрованные по адресу записи |
| Чтение | Не удаляет записи и не меняет курсоры других клиентов |
| `lost` | Потери журнала шины и канала до фильтра адреса; не число потерянных аппаратных кадров |
| `reset=true` или новая сессия после длительного разрыва | Чтение без `after` |
| Курсор и uptime | Не являются уникальным идентификатором загрузки |

### Запись журнала

| Поле | Значение |
|---|---|
| `id` | Номер записи; десятичная строка, 64 бита |
| `time_us` | Время PS |
| `type` | Тип события или телеметрии |
| `status` | Статус сервиса |
| `source` | Источник действия |
| `operation` | 0 — чтение, 1 — запись |
| `address`, `reg`, `value` | Устройство, регистр, значение |

| `source` | Источник |
|---:|---|
| 0 | Консоль |
| 1 | Внешний ведущий |
| 2 | DCP2 |
| 3 | Внутренний сервис |
| 4 | Web |

| `status` | Значение |
|---:|---|
| 0 | OK |
| 1 | Malformed |
| 2 | Unsupported |
| 3 | Denied |
| 4 | Busy |
| 5 | Timeout |
| 6 | Range |
| 7 | Not ready |
| 8 | Not found |
| 9 | IO |
| 10 | Internal |

| Тип события | Значение |
|---:|---|
| 1 | Попытка |
| 2 | Завершение |
| 3 | Отказ политики |
| 4 | Состояние |
| 5 | Ошибка |

| Тип телеметрии | Наблюдение |
|---|---|
| 257 | Внешняя запись, потреблённая PS |
| 258 | Результат физического чтения master |
| 259 | Результат физической записи master |
| 260 | Установка указателя регистра I²C slave |
| 261 | Запрос чтения I²C slave, без значения данных |
| 262 | Подготовленный байт ответа I²C slave, не подтверждённое чтение |

| Условие | Смысл `value` |
|---|---|
| Ошибочное master-чтение | 0 — заполнитель без достоверных данных |
| Тип 260 | Байт указателя, не запись регистра |
| Тип 262 | Подготовленный байт; приём внешним ведущим не подтверждается |
