# Файловые маршруты HTTP

[Общие требования](common.md). Ограничения прежних файловых URL заданы отдельно.

## Тома и SD-PL

| GET-маршрут | Поля ответа |
|---|---|
| `/api/ui/volumes` | `volumes`: записи томов в порядке `flash`, `sd`, `sd-pl` |
| `/api/ui/sd-pl` | `ready`, `mounted`, `filesystem_owned`, `ocr`, `block_addressed`, `last_lba`, `last_error`, `format_allowed:false` |

| Поле записи тома | Значение |
|---|---|
| `name` | Имя тома |
| `ready` | Готовность |
| `fat_bits` | Тип FAT; 0, если неизвестен |
| `total_bytes`, `free_bytes` | Байты; `null`, если неизвестны |
| `format_allowed` | `false` |

| Условие | Ограничение |
|---|---|
| Статистика Flash и PS SD | Кэшируется до 30 секунд |
| Размер SD-PL | Размер FAT-тома; `free_bytes=null` |
| `/api/ui/sd-pl` при доступном описании тома | Дополнительно `fat_bits`, `volume_lba`, `volume_sectors` |
| Оба GET | Без монтирования, форматирования, повторной инициализации или сырого теста секторов |

## Каталоги и файловые операции

| Query | Требование |
|---|---|
| `volume` | `flash`, `sd`, `sd-pl`; смонтированный том, без автоматического remount |
| `path` | Абсолютный путь внутри тома; до 120 байт UTF-8 |
| Компонент пути | До 63 байт UTF-8 |
| Запрещено в пути | `.` и `..`, пустые компоненты, конечные пробелы и точки, `\`, `:`, управляющие и зарезервированные FAT-символы |
| Корень `/` | Только для чтения каталога |

`GET /api/ui/files`:

| Параметр или поле | Значение |
|---|---|
| Query `offset` | По умолчанию 0; максимум 100000 |
| Query `limit` | По умолчанию 64; 1–128 |
| Query `action=stat` | Одна запись объекта без `entries` |
| Ответ | `entries`, логический `ok`, числовой `error`, `next` |
| Запись | `name`, логический `directory`, `size`, `date`, `time` |
| `next` | Смещение следующей порции или `null` |
| `size` | Байты |
| `date`, `time` | Упакованные поля FAT; 0 — неизвестно |
| Между страницами | Каталог не блокируется; внешнее изменение требует нового перечисления |

`PUT /api/ui/files`: обязательны `confirm=true` и `action`; тело отсутствует.

| `action` | Дополнительные query | Ограничение |
|---|---|---|
| `mkdir` | — | Один каталог; родитель существует |
| `remove` | — | Файл или пустой каталог; без рекурсии |
| `rename` | `dst_volume`, `dst` | Один том; без перезаписи |
| `copy` | `dst_volume`, `dst` | Один файл; между томами разрешено; без перезаписи и создания родителей |

## Содержимое файла

`/api/ui/file` использует `volume` и `path` из общей таблицы.

| Метод | Параметр или свойство | Значение |
|---|---|---|
| GET | Ответ | Двоичное тело с Content-Length |
| GET | `max_bytes` | Необязательный предел до передачи; превышение — 413 |
| GET | Ошибка после заголовков | Ответ обрывается; HTTP 200 не подтверждает полноту |
| PUT | `confirm` | Обязательно `true` |
| PUT | `overwrite` | По умолчанию `false`; существующий файл — 409; `true` разрешает усечение |
| PUT | Тело | Потоковая запись блоками 1024 байта; максимум UINT32_MAX и ограничения носителя |
| PUT | Успешный ответ | После синхронизации и закрытия: `ok:true`, `bytes`: число записанных байтов |

| HTTP-код | Условие |
|---:|---|
| 400 | Неверное имя или параметры |
| 403 | Запись запрещена |
| 404 | Объект отсутствует |
| 409 | Цель существует |
| 423 | Том занят |
| 503 | Том или файловая система не готовы |
| 500 | Прочая ошибка FatFs |

| Свойство | Ограничение |
|---|---|
| Ошибка FatFs | Числовой код включается в описание |
| Сетевой обрыв | Ответ может отсутствовать; частичный целевой файл сохраняется |
| Откат и автоматические повторы | Отсутствуют |
| Форматирование | Не предоставляется |

## GET /api/fs и GET /api/qspi

`/api/fs`: объект `volumes`, всегда записи `flash` и `sd` в этом порядке.

| Поле записи | Тип | Смысл |
|---|---|---|
| `name` | Строка | `flash` или `sd` |
| `ready` | Логическое | Готовность контекста тома |
| `total_bytes` | Целое | Вместимость по статистике FAT, байты |
| `free_bytes` | Целое | Свободное место по статистике FAT, байты |

| Условие | Значение |
|---|---|
| Статистика не получена, включая ошибку блокировки или `f_getfree` | Размеры 0 независимо от `ready` |
| PL SD | В `/api/fs` отсутствует |
| `/api/qspi` | Логический `ready`, целые `fs_base_bytes`, `fs_size_bytes` |
| `fs_base_bytes`, `fs_size_bytes` | Программно выделенное окно, не обнаруженная геометрия чипа |

## Файлы, TAR и статика

| Путь URL | Данные устройства |
|---|---|
| `/sd/x` | Файл `sd:/x` |
| `/flash/x` | Файл `flash:/x` |
| `/tar/sd/x` | Дерево `sd:/x` |
| `/tar/flash/x` | Дерево `flash:/x` |
| `/` | `flash:/www/index.html` |
| `/css/app.css` | `flash:/www/css/app.css` |

### Чтение файла и архива

| Запрос | Ответ или ограничение |
|---|---|
| Файловый GET | Двоичное тело и длина; каталог не перечисляется |
| Отсутствующий файл | 404 |
| TAR GET | `application/x-tar`; заголовки до завершения обхода |
| Ошибка обхода после заголовков | Не меняет HTTP 200; архив может быть неполным |
| Параллельные изменения файлов | Согласованность архива не гарантирована |

### Загрузка файла и архива

| Запрос | Действие | Ответ |
|---|---|---|
| Файловый PUT | Создание или усечение; прямая запись | 200 `OK`; ошибка тела — 400, открытия или записи — 500 |
| PUT `/tar/flash/<каталог>` или `/tar/sd/<каталог>` | Извлечение с возможной заменой файлов | 200 `OK` или 400 `tar extract failed` |

Откат отсутствует. Загрузка JSON не применяет конфигурацию к сервису.

### Ошибки и обработка путей

| Условие | Правило |
|---|---|
| Неготовый том или отказ блокировки | Возможно закрытие без HTTP-ответа; обязательного 503 нет |
| Кодирование | URL-декодирование |
| Фильтр пути | Запрещены любая подстрока `..` и двоеточие; для статики также обратный слеш |
| Query в файловых URL | Не поддерживается единообразно; не передаётся |
| Каталог статики с конечным `/` | Добавляется `index.html` |
| Неподдержанный путь | Может перейти к поиску статического файла |
