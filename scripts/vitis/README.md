# Сценарии FreeRTOS и JTAG

`build.sh` загружает локальную конфигурацию и вызывает `build.tcl`.
Последний формирует платформу/BSP и выбранное представление исходников.
`run_jtag.sh` загружает аппаратные файлы и ELF либо подготавливает GDB.

- [Сборка FreeRTOS и вариант с SSH](../../docs/build/freertos.md).
- [Загрузка через JTAG](../../docs/build/jtag.md).
- [Отладка](../../docs/build/debug.md).
- [Параметры сценариев](../../docs/reference/build-options.md).

Образцы локальных файлов: `build_vitis.conf.example` и
`run_jtag.conf.example`. Не перезаписывайте существующую конфигурацию
при переносе инструкции. Обычная сборка может удалить `vitis_ws`;
все исходные изменения должны находиться вне производного каталога.
Для повторной сборки без запуска Eclipse используйте `CLEAN=0 ./build.sh
freertos`; режим работает только с проверенным workspace, созданным полной
сборкой.

`build_ssh_deps.sh` собирает проектные wolfSSL/wolfSSH в
`build/ssh-deps/`. Секреты SSH передаются через защищённое окружение
и не включаются в Git.
