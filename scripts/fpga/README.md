# Сценарии аппаратной сборки

`build_fpga.sh` создаёт проект из внешнего `Burevestnik_21.tcl` и
вызывает `build_hw.tcl` для реализации и экспорта `design.bit`/`design.xsa`.
Штатный результат находится в `artifacts/fpga/`, журналы —
в `artifacts/vivado/logs/`.

- [Подготовка и запуск](../../docs/build/fpga.md).
- [Все параметры и приоритеты](../../docs/reference/build-options.md#аппаратная-сборка).
- [Контракт AX7020](../../docs/reference/board.md).

Локальная конфигурация создаётся из `build_fpga.conf.example`.
Параметр `--clean` удаляет производный `vivado_project` во внешнем
аппаратном каталоге. Перед ним сохраните ручные изменения. Старые
обёртки совместимости не являются основным путём для новых инструкций.
