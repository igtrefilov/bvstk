# P24C02A

Пакет для EEPROM Puya P24C02A: 256 байт, страницы записи по 8 байт.
Описание микросхемы: [P24C02A V2.1](https://www.puyasemi.com/download_path/%E6%95%B0%E6%8D%AE%E6%89%8B%E5%86%8C/EEPROM/P24C02A_Datasheet_V2.1.pdf).

| Файл | Назначение |
|---|---|
| `p24c02a.json` | Подключение, обмен, политики и фоновое чтение |
| `register_map.json` | Все байты диапазона `0x00–0xFF` |
| `view.js` | Форма просмотра памяти во вкладке «Параметры» |

## Наполнение кэша

После подтверждения готовности PS читает весь диапазон по одному байту.
Между операциями одного устройства задана пауза 10 мс. Следующий проход
начинается через 5 секунд после завершения предыдущего. Ошибочная операция
повторяется через 2 секунды; занятость шины может увеличить задержку.

Побайтовое чтение сохраняет циклическую адресацию `read_sequence: wrap`.
Выбор канала свитча и восстановление прежнего маршрута выполняет общий
I²C-сервис. План `acquisition` применяется при старте PS. Начальные значения
для памяти отсутствуют. Исходная политика записи содержит пустой whitelist.

## Форма

Память показана таблицей HEX и ASCII. Выбор ячейки открывает десятичное
значение, символ, биты, страницу записи и метку времени от старта системы.
Стрелки перемещают выбор; поле адреса принимает HEX от `00` до `FF`.
Обновление данных сохраняет фокус, выделение, прокрутку и раскрытые блоки.

Форма принимает достоверные байтовые значения из физического кэша
с источником `I2C` или `read` и временной меткой. Неизвестные байты показаны
знаком `—`. При потере достоверности ранее полученный байт остаётся серым
как последнее известное значение. Он исключается из счётчика достоверных
данных и из полного экспорта. Значения из `settings` не заполняют форму.

«Пауза» фиксирует таблицу, подробности, счётчики, журнал и временные метки.
Фоновый сбор продолжает работать. «Продолжить» показывает последний
полученный снимок вместе с наблюдавшимися за время паузы изменениями.
Выбор другого байта на паузе показывает данные зафиксированного снимка.

Журнал сравнивает соседние достоверные наблюдения каждого байта.
Первое чтение, повторение прежнего значения и потеря достоверности
не создают запись об изменении. После разрыва наблюдений первое значение
задаёт новую точку сравнения. Журнал хранит последние 200 изменений;
счётчик затронутых адресов учитывает весь сеанс вкладки. Перезапуск PS,
смена устройства и повторное открытие формы начинают новый сеанс.
Промежуточные изменения между чтениями и между HTTP-снимками могут быть
пропущены. Это история наблюдаемого содержимого; решения политики
и попытки записи доступны во вкладке «События».

«Снимок .bin» сохраняет показанные 256 байт в файл браузера. Кнопка
доступна при полном достоверном кэше и подтверждённой связи в отображаемом
снимке. Во время паузы сохраняется зафиксированный снимок. Имя содержит
ID устройства и последнюю метку времени. Байты читаются последовательно,
поэтому файл не является атомарным снимком всей микросхемы.

Назначение хранящихся данных задаёт приложение. Для расшифровки серийного
номера, сетевых адресов и других полей нужно описание их расположения.
Значения `00` и `FF` сами по себе не обозначают свободную память.

## Обновление установленной системы

Файлы пакета размещаются вместе в `flash:/config/i2c/pca9545a/p24c02a/`.
При обновлении сохранённого профиля добавляют `acquisition`, сохраняя
его адрес, маршрут, политики и настройки. Затем перезапускают PS.
Веб-файл `js/device-view.js` также требуется обновить: он разрешает
скачивание локального снимка из изолированной формы. Доступ формы к сети,
операциям шины и DOM основной страницы остаётся закрытым.
