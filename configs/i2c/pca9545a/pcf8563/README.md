# PCF8563

Бандл часов реального времени: профиль, карта 16 регистров, форма
«Показатели» и пиктограмма. Адрес и маршрут задаются в `pcf8563.json`.

## Получение данных

Профиль включает фоновое чтение 0x00–0x0F одним блоком с интервалом
1000 мс после завершения предыдущего чтения. План запускается при
готовности устройства. После ошибки действует задержка повтора 2000 мс.
Чтение этих регистров сохраняет флаги VL, AF и TF.

Сервис PS передаёт в HTTP-кэше идентификатор блочного чтения `read_id`
и его длительность `read_duration_ms`. Форма объединяет календарь,
когда регистры 0x02–0x08 принадлежат одному чтению длительностью менее
1000 мс и содержат допустимые значения BCD. Проверяется также допустимое
число дней в месяце с учётом двузначного года RTC.
При раздельных чтениях или старом API видны отдельные поля с метками времени.

Данные обновляются независимо от открытой страницы. Кнопка «Пауза»
фиксирует всю форму; «Продолжить» показывает последний полученный снимок.
Время меняется только при обновлении кэша. Значения старше пяти секунд
или полученные до потери связи отмечаются как устаревшие.
Начальные значения `settings` не используются для показателей.

## Карточки

| Карточка | Содержимое |
|---|---|
| Время и календарь | Часы, минуты, секунды, дата, двузначный год, код дня недели, бит века |
| Состояние часов | VL, STOP, TEST1, TESTC, согласованность календаря, заполнение кэша |
| Будильник | Условия совпадения, исключённые поля, AF, AIE |
| Таймер | Текущий двоичный счётчик, частота, оценка остатка, TF, TIE |
| CLKOUT | Заданная частота, FE, влияние STOP и режима внешнего такта |
| Прерывание | Запрос по AF/AIE и TF/TIE с учётом импульсного режима |
| Основания показателей | Все 16 байтов, пояснения и метки чтения |

Век, названия дней недели и часовой пояс зависят от соглашения ПО,
работающего с RTC. Поэтому показаны исходный двузначный год, C и код дня.
VL указывает на возможную потерю времени; напряжение и заряд батареи
микросхема через этот флаг не сообщает.

Счётчик таймера продолжает работать во время чтения. Оценка `N / f`
относится к последней выборке. Для точного счётчика NXP рекомендует два
совпавших чтения; форма не считает такую проверку выполненной.
Уровень INT и фактическая частота CLKOUT не измеряются; отображаются
флаги и настройки. AF и TF могут оставаться установленными после события.

## Обновление

Нужны актуальный PS и файлы `pcf8563.json`, `register_map.json`, `view.js`,
`icon.js` в каталоге устройства во Flash. План чтения применяется при
старте PS. Код формы выполняется в браузере в изолированном iframe.

Источник: [NXP PCF8563, Rev. 11.1](https://www.nxp.com/docs/en/data-sheet/PCF8563.pdf),
разделы 8.3–8.10 и требования к длительности доступа I²C в разделе 13.
